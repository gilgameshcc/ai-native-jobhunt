### ③ 这几天该做什么

> ⭐ **这一块有三种措辞（⛔ 旧版只有两种），⛔ 不许现场挑 —— 按第〇节「本次的决策时点」那一格自动选。判据纯字面**：那一格填的是"正在做决定" → **A**；填了一个过去的日期、**且那件事已经结束、今天不可能再动** → **B**；⭐ 填了一个过去的日期、**但那个决定今天仍在继续、今天仍然做得了动作** → **C**。⛔ 那一格空着不许猜，回去把它问出来。
> ⭐ **B / C 分不清时缺省走 C**（保守缺省）：⚠️ **判成 B 的代价是把一个今天能做的动作推到"下次"，判成 C 的代价只是多写一条今天做不了的动作** —— ⛔ **两个方向的代价不对称。**
>
> **A · 正在做决定（缺省）** → **保持现状**：标题就是上面这句「这几天该做什么」，逐条写动作。
>
> ⭐ **B · 回溯 · 复盘** → ⛔ **上面那句用不了**（事情已经发生了，没有"这几天"）。⭐ **标题改写成「这一次已经定了的，和下一次要提前做的」，分两段写**：
> - **① 这一次已经定了的部分** —— 照实写，⛔ **这一段不出动作**（它已经不可改了）
> - **② 下一次遇到同类处境时，提前做什么** —— ⛔ **每条的措辞必须落在"下次"**：「**下次在 ＿＿ 之前，先 ＿＿**」
> - ⛔ **不许写成「你当时应该……」。理由**：**回溯的用途是让下一轮不再漏，不是让人后悔。**「你当时应该」这句话**产出零个可执行动作** —— 它读起来像一条建议，⚠️ **而没有任何人能执行它**（那个时点已经过去了）。
>
> ⭐ **C · 决策在过去做出、但至今仍在继续（⛔ 新增，⛔ 不许拿 B 去凑）** —— 典型：当初定了留下 / 定了接，而那件事**今天还在过着**，且**今天仍然动得了**。⚠️ **A 和 B 都不合身**：A 假设"决定还没做"，⛔ **而 B 写死"这一段不出动作 + 措辞落在下次"，于是"今天就该发的那封邮件"被措辞推到了「下次」**。⭐ **标题改写成「当初定的那件事，和今天还能动的那部分」，同样分两段写**：
> - **① 当初定的是什么、当时依据的是什么** —— 照实写，⛔ **这一段不出动作**（与 B 的第 ① 段同）
> - ⭐ **② 今天还能动的那部分** —— ⛔ **每条的措辞必须落在"今天"**：「**今天就 ＿＿**」。⛔ **不许落在"下次"**，⛔ 更不许写「你当时应该……」
> - ⭐ **「还没问、但今天问一句就有」的那几条在 C 里落在第 ② 段**，措辞照 A：「**今天给 ＿＿ 发一句：『＿＿？』**」
>
> ⛔ **三种措辞下都不变的**：每条必须是一个具体动作，**做什么 · 找谁 · 原话说什么**。⛔ 不许写「再想想」「多了解一下」「谨慎评估」。
> ⭐ **A 专属**：没有一列能合法排第一时，第 1 条就是把那件缺的东西补上（把那句话问出来 / 写下一条自己的底线 / 把租约落实）；「还没问、但今天问一句就有」的那几条排最前面（判据见第二节末尾的四类诊断），照着写：「**今天给 ＿＿ 发一句：『＿＿？』**」。⛔ 不许把它们和"真的拿不到的那些"混成一句「信息还不够」。

### 估算误差带（⭐ 排序之前先填，⛔ 不许排完再回头调）

> 「差幅小于这一维的估算误差带就换下一维说」这条规则，只有在误差带**事先定好**时才成立。同一份数据，误差带取 ±1 和取 ±5 会得出**两条不同的决胜维**。
>
> ⭐ **比较口径也写死，只有一种读法：差幅必须严格大于该维误差带的绝对值，才算"分得出来"。**（例：误差带 ±5，两列差 5 指数点 → **分不出来**；差 6 才算分得出来。）⛔ 不许读成"两列各带 ±N、区间重叠即分不出来"（那等于把门槛悄悄放大一倍），⛔ 更不许现场在两种读法之间挑 —— **两种读法在同一份数据上会给出不同答案。** 定性三档的那几维照旧：**相邻一档视为分不出来，跨两档才算分得出来**。
>
> ⭐ **最小路径只有一维，没有"下一维"可换。** 唯一那一维分不出来时 ⛔ **不许走「分不出来」出口**（那个出口要求"先只用 `你给的` / `公开可查` 的那几维重排一次"，最小路径没有"那几维"）→ **直接进深潜加第二维**，并说一句「这一步开始就不是最小路径了」。
>
> ⭐ **深潜里同一个死结也要补（⛔ 此前没补）**：⚠️ **实跑里常常一维全硬的都没有**，那个出口的第 1 条字面上无法满足 → 整个走不通。⭐ **条件 1 改成两层，⛔ 按顺序试**：**① 第一层（原口径）** 存在至少一维每一格都硬 → 只用这些维重排；⭐ **② 第二层（一维都没有时用）—— 降到格**：每一维取它的 `可比` 列（至少有一格硬的那几列），**只在这几列之间比**，逐维写明「这一维只有 ＿ 列可比」，⭐ **只要有任何一对在任何一维上分得出来，就照常出排序**；**③ 两层都跑完还分不开**，才算满足条件 1，并写一句「**本次没有任何一维是全部可追溯的，我已经降到单格重排过一次，仍然分不开**」。⛔ 不许跳过第二层直接宣布分不出来。

|---|---|---|---|---|
| ① 真实时薪（指数） | 默认 **±5 指数点** | `默认建议值` | 第 ＿ 轮 · 未改 / 第 ＿ 轮改为 ±＿ | |

> ### ⭐ 第三档：`方向确定 · 量级不明`（⛔ 旧版只有"分得出来" / "分不出来"两档）
>
> ⚠️ 某一维上有一条**方向明确的硬差异**（A 比 B 好，这一点是确定的），⛔ **但材料里零金额、零刻度，量级判不出来** —— 旧版两档里它只能落进「这一维分不出来」，⭐ **于是它和"两列真的差不多"在这张表里长得一模一样**。⛔ **而两者的下一步动作正好相反**：前者是「换下一维，别再管了」，⭐ 后者是「**这一维已经有结论了，缺的只是差多少**」。
>
> ⭐ **判据写死，纯字面，一眼判**：**这一维上有没有一条 `你给的` 或 `公开可查` 的事实，能确定 A 优于 B（哪怕说不出优多少）？有 → `方向确定 · 量级不明`；⛔ 没有 → 才是「这一维分不出来」。**
>
> - ⛔ **`我推测的` 撑不起这一档**（连同 `你给的（原话记不清）` 与上游标 `未验证` 的那些）：**靠推测得出的"方向"不是方向，是猜**
> - ⛔ **也不许拿"我算了一下大概是 A 高"去凑** —— 那是一个算得出差幅的比较，⛔ 不进这一档
> - ⭐ **它算「分得出来」的一种**，⛔ 不许当成「分不出来」扔掉，⛔ 也不许因为它"没有数"就整维退出
> - ✅ **排序时可以用它定先后**；⛔ **不能用它算差幅**，⭐ **因此 ⛔ 不能用来判决胜维**；⛔ **也不能拿它写翻转点**（翻转点必须带临界取值，这一档没有可落在刻度上的取值）—— ⚠️ **唯一的例外是下面那条「跨一年以上的趋势」**
> - ✅ ⭐ **它能触发第三节的「两维方向相反」出口（⛔ 旧版接不上，这是一处硬断裂）** —— ⚠️ 那个出口的触发判据字面要求"差幅严格大于误差带 / 定性维跨两档"，⛔ **而这一档两样都没有**，于是「一维是第三档、另一维与它方向相反」**两个出口都够不着**。⭐ **写死：这一档算"分得出来"的一种，因而照样触发方向冲突出口**（两维都是这一档时同样走），⛔ **走进去之后不许说"差多少"**
> - ⭐ **第三节的措辞写死**：「**这一维 ＿＿ 优于 ＿＿ 是确定的，但优多少不知道。**」⛔ 不许简化成「＿＿ 更好」（丢掉了"多少不知道"），⛔ 更不许写成「这一维分不出来」（丢掉了已经拿到的那个结论）
> - ⭐ **第五节必须配一句能问出量级的具体问法**（⛔ 不许只写「再确认一下这一维」），问法落在**这一维自己的刻度**上。例：真实时薪那一维 →「这两边在这一条上，差的是几成，还是成倍？」；定性三档的那几维 →「这两家在这一条上是差一档还是差两档？各举一件具体发生过的事。」
> - ⭐ **名次完全由这一档定出来时，第三节「差在哪一维」那一栏照着写**（⛔ 别留空、⛔ 别硬编一个决胜维）：「**本次第 1↔2 的先后，是由『＿＿这一维上 ＿＿ 优于 ＿＿ 是确定的』定出来的；⛔ 这一维没有量级，所以本次没有决胜维。**」

> ### ⛔⭐ 跨越一年以上的比较：看的是斜率，⛔ 不是相邻两次的差
>
> ⚠️ **「相邻一档视为分不出来」在多年尺度上会系统性抹掉缓慢下滑** —— ⭐ **三年滑三档，每年看都是相邻一档**，于是每一次比较都判"分不出来"，⛔ **三年下来的那三档在输出里一点痕迹都不剩**。⭐ **多年尺度要的是斜率，而框架里没有斜率。**
>
> - ⭐ **触发判据（字面）**：这一维上**最早那次观察与最近那次观察之间跨了一年以上**（按各自的**材料日期**算）。⛔ 跨不到一年 → 不触发
> - ⭐ **趋势的判据（字面）**：**同一维上连续两次观察同向**（连着两次都在往下 / 都在往上，⛔ 中间没有一次反向）→ 记为一条**趋势**。⚠️ **两次同向就够，⛔ 不要求三次** —— 门槛定到三次，这条规则在真实材料上**恒不触发**，⭐ **和一条坏掉的规则无法区分**
> - ⭐ **每次观察必须带它的时点**；⛔ **没有时点的观察进不了趋势判定**
> - ⭐ **趋势按 `方向确定 · 量级不明` 处理**：✅ 可以定先后；⛔ 不能算差幅、⛔ 不能判决胜维
> - ⛔ **不许把三次观察各自跟误差带比一遍、然后说"三次都分不出来"** —— ⚠️ **那是把一条趋势拆成三次分不出来**
> - ⭐ **措辞写死**：「**这一维上，从 ＿＿ 到 ＿＿ 是一路在往下走的（＿＿→＿＿→＿＿）；每一步都小到分不出来，但方向连着没变过。**」⛔ 不许简化成「这一维分不出来」，⛔ 也不许写成「跌了三档」
> - ⭐ **它是第三档里唯一能写进第四节翻转点的一种**，临界取值 = **「连续两次观察反向」**（二值）。⛔ 别推广到第三档的其余情形

> ### ⛔ 用户覆盖误差带：三条硬约束（这是本节唯一的口子）
>
> 实测：一组**薪资结构完全同构**的样本（同薪数、都无浮动、同社保缴纳地），top2 真实时薪差 1.4 指数点 —— **±5（默认）→ 决胜维是生活成本 → A 第 1；±1（用户声明）→ 决胜维是真实时薪 → B 第 1**。**换掉的不只是决胜维，是名次。**
>
> 而「⛔ 不许排完序再回头调」拦不住它：用户看完排序再说一句「误差带该按 ±1」，触发的是「用户取值优先于默认」，**两条规则直接对撞**。所以：
>
> 1. ⛔ **收窄要给理由，且理由要对得上具体哪一项估算**（例：「我有考勤打卡数据，工时不是估的」→ 对应 ±5 里给「工时自估」留的那部分余量）。**给不出理由的按默认走**，并在这里写一行「用户要求收窄至 ±N，未给出对应依据，本次仍按默认 ±M」
> 2. ⭐ **只要覆盖了任何一维，就同时按默认值再跑一遍**：名次相同 → 正常输出；**名次不同 → 必须明写「按你给的误差带是这个顺序，按默认误差带是另一个顺序 —— 这个结论完全建立在你对自己数据精度的判断上」**；名次同但决胜维变了 → 也写一行
> 3. ⭐ **误差带表（⛔ 是误差带那一张，不是紧挨着的可分性判定表）的「声明于第几轮」那一列不许空。** 理由：**一个从来没被观测到「先声明」过的先后约束，和一个没有这条约束的模块无法区分。** 这条规则在机械层面无痕，它就只是一句话
>
> ### ⛔ 裁决：误差带不做三点采样
>
> **你需要误差带来判断采样结果算不算变化，再去采样误差带本身是循环的。** 误差带是那把尺子，不是被量的东西——它改用上面三条约束（要理由 / 两套都跑 / 留痕）。

### ⭐ 还在流程中、尚未成为 offer 的机会（⚠️ 很可能是最常见的形态之一）

- ⭐ **给它一列，带 `未成 offer` 标记：进表，但 ⛔ 不参与排序、⛔ 不给名次（哪怕是最后一名）**

| # | 判据 | 本次（成立 / 不成立 / ⭐ 判不出来） |
|---|---|---|
| 1 | **时间上够得着**：对方给得出的下一步时间点够得上你的答复截止 —— ⭐ **要问出来，⛔ 不许推测**。⭐ **没有提问对象、或答复截止 `未知` → 记 `判不出来`**，⛔ 不许因此判 `不成立`。⭐ **答复截止是 `结构上不存在` 时，拿你自己设的那个日期当比较对象**，⛔ 不记 `判不出来` | |

## 一、Gate（必要条件，先过这一关）

> ⛔ **必要条件不满足 → 直接出局，不进下面的排序。** 加分条件再多也换不掉一条必要条件。
>
> ⛔ **必要条件的约束力来自它写在你看到这些 offer 之前。** 它的全部价值就在于决策当下不许改。
>
> ⚠️ **现在才想出来的那条，不降级，仍然进 gate——但要「两套都跑」**：标注 `事后重构`，然后**含它跑一套 / 不含它跑一套**。两套结论相同就写一句「结论不依赖它」；**不同就必须明写「你的结论取决于一条你事后才想起来的条件 —— 它是 X，先决定这条到底算不算你的底线」**。⛔ 不许替用户裁决，⛔ 不许只输出其中一套。
>
> ⚠️ **旧版的「降级为加分条件」是错的，别再那么填。** 它假设用户想让事后条件**算数**，所以降级是惩罚；但用户心里已经想去 A、而 A 违反了一条不可闭合底线时，他只要答一句「现在才想的」，gate 就空了——**降级正是他要的结果**。⭐ 顺手把这条写进第七节存档，下次它就是事前的了。
>
> ⭐ **「说不清 / 记不清」按事前算**（保守缺省）。这一格无人可验证，缺省必须偏向保留约束，否则「记不清了」就是一句零成本的万能解除键。
>
> ### ⭐ 填这一节之前：先看工作区有没有 `positioning.md`
>
> ⛔ **不许从零重问必要条件。** 有 `positioning.md` 就**直接接过来**，且 ⭐ **写下时点按那个文件里记的日期判，⛔ 不按"今天跟 agent 说的时间"判** —— 一条几周前手写下来的真·事前条件，被当场重问一遍就会变成"今天才说的"，进而被降级成 `事后重构`。文件里没记日期的，按「说不清」→ **按事前算**。
>
> | `positioning.md` 里的 | 落到本表哪里 |
> |---|---|
> | **必要条件** | 下面的 N1-N3，走全套判定 |
> | **加分条件** | 本节末尾的加分条件表（不出局，**也不发通行证**） |
> | ⭐ **硬性排除条件** | ⭐ **也进下表，但语义是「短路」：命中即出局。⛔ 没有「有条件满足」这一档，⛔ 不许降档、不许用代价换、不许摊销。** 必要条件里有一部分是可闭合的，**硬性排除永远不可闭合** |
>
> ### ⭐ gate 的输入通道有三条，⛔ 不是两条
>
> ⚠️ **这很可能就是上一轮 gate 从没跑起来的根因。** 旧版只有 ① `positioning.md` 与 ② 让用户当场写 —— ⭐ **两条都要求"用户在场"**，于是**任何离线 / 转述 / 材料型输入最多只能走到 `无 gate`**：⚠️ **它对所有此类输入给同一个结论，因而与一条坏掉的规则无法区分。**
>
> | # | 通道 | 判据 | 写下时点按什么算 |
> |---|---|---|---|
> | 通道 1 | **`positioning.md`** | 工作区里有这个文件 | ⭐ **按文件里记的日期** |
> | 通道 2 | **用户当场写下** | 用户在场且写得出 | 今天 → 冷启动分支 |
> | ⭐ 通道 3 | ⭐ **从已有书面材料里认定** | 见下面的字面词表 | ⭐ **按那份材料的日期**，⛔ 不按今天 |
>
> ⭐ **通道 3 的提取判据：看那句话里有没有排他性措辞，⛔ 不看"你觉得他在意什么"**：
>
> > **A · 禁止型**（书面 / 正式表述里最常见）
> > **「我不可能……」· 「这个不行」· 「必须要……」· 「一定要……」· 「没有 ＿＿ 我就不去」· 「再也不……」· 「绝对不……」· 「受不了……」· 「底线是……」**
> >
> > ⭐ **B · 排序型 / 拒绝型口语**（⭐ **这一组才是人说话时最常见的形态**）
> > **「不是 ＿＿，是 ＿＿」· 「＿＿无所谓，先保 ＿＿」· 「＿＿我认了，但 ＿＿ 不行」· 「＿＿（一旦发生）我就 ＿＿」· 「和我现在的处境不是一回事」· 「再多 ＿＿ 也换不了 ＿＿」· 「我可以 ＿＿，但前提是 ＿＿」**
>
> ⛔ **词表之外的句子不许提取**（「我比较喜欢 A」是**偏好** → 去加分条件表）。
>
> ### ⛔⭐ 自我说服自查（⛔ 通道 3 提取之后、进下表之前跑一次，⛔ 一次都不许省）
>
> ⚠️ **这是补 B 组词表带来的副作用。** ⭐ **真人最常用「不是 A，是 B」「＿＿无所谓先保＿＿」这种句式的时刻，恰恰是在说服自己** —— 于是提取出的"底线"**很可能就是他那段自述的结论**，⭐ **等于拿一个人的结论去检验他的结论**。⚠️ 实跑里有一份材料的最后一句正是「你说我是不是在给自己找理由」，⛔ **框架结构性地答不了。**
>
> ⭐ **数两样，都是字面的**：
>
> 1. ⭐ **每条候选条件"照顾"的是哪一列** —— 逐列判一次「满足 / 不满足」：**只有一列判满足** → 记它**指向那一列**；**判满足的不止一列、或一列都不满足** → 记 `不指向任何一列`（⛔ 不参与计数）。⭐ **分别指向不同列 → 正常走，⛔ 不标记；全部指向同一列 → 进第二样**
> 2. ⭐ **那一列是不是他自述里字面倾向的那个** —— 材料里有没有一句**字面指向那一列**的倾向表达（「我想去 ＿＿」·「我更倾向 ＿＿」·「我基本上定了 ＿＿」·「你说我是不是在给自己找理由」）。⛔ **没有这样一句 → 不标记**
>
> ⭐ **两样都成立 → 那几条整组标 `可能是自我说服`**（第〇节那一格填"是"）。**然后**：
>
> - ⛔ **不许单独踢人、⛔ 不许单独触发上位出口** —— ⚠️ **哪怕用户不在场也不许**
> - ⭐ **必须原话回读，问一句写死的话**：**「你说的『＿＿』『＿＿』『＿＿』三条都指向同一个选择。这可能是你真的有这三条底线，也可能是你已经想好了要去哪一家，正在给这个决定找理由。—— 哪一种？」**
> - **答"是我的底线"** → 标记去掉，按 `待你确认` 正常路径走 · **答"我是在找理由"** → 这几条**移到加分条件表**，⛔ 不许留在 gate 里
> - ⭐ **用户不在场** → **结论照出**，⛔ **但必须带那句写死的声明**（见一页纸译法表），⭐ 并写进第四节翻转点（临界取值 = 二值的「这几条到底是底线，还是找出来的理由」）
>

> ⭐ **提取出来的必须回读确认，确认前标 `待你确认`**：⚠️ 这里有一个真实的两难 —— **提取并直接当成必要条件 = agent 替用户立法；不提取 = 明明有信息却判「一条都没有」**。⭐ **`待你确认` 就是这两者之间的那一档**：条件**进表并起作用**（因而不再是 `无 gate`），同时**明写它不是用户亲口立的法**。
>
> - 回读一句：**「你说过『＿＿』—— 我把它当成一条必要条件，对吗？」**
> - **确认** → 转正常必要条件（写下时点按材料日期）· **否认** → 移到加分条件表 · **没回答 / 不在场** → ⭐ 保持 `待你确认`
> - ⛔ **`待你确认` 的条件判出「不满足」时，缺省 ⛔ 不许直接判出局** → 改判 **`gate 待定`**（留在排序里、不能排第一）。⚠️ **一条用户没确认过的底线，不该由 agent 拿去踢掉一个选项**
>
> ### ⛔⭐ 但这条缺省有一个例外 —— 判据是「**那一格的取值有多硬**」，⛔ **不是「用户在不在场」**
>
> ⭐ 一句话说破：**拿"他没确认这是他的底线"，去挡住"他自己说了这件事不成立" —— 挡错了对象。**
>
> ⭐ **一条 gate 判定有两个部分，它们的不确定性完全不同**：
>
> | | 是什么 | 确定吗 |
> |---|---|---|
> | **条件** | 「我要 ＿＿」 | ⚠️ 是**我从你材料里认定的**，**你没确认过** |
> | ⭐ **那一列在这条上的取值** | 「这一列**没有** ＿＿」 | ⭐ **可能非常硬** —— 有时就是**用户本人白纸黑字说的** |
>
> ⭐ **`待你确认` 标的是左边那栏。** ⛔ **而旧规则拿它否掉了整行，连右边那个硬事实一起否掉了。**
>
> **例外的适用条件（⭐ 四条同时成立，纯字面）**：
>
> 1. ⭐ 那一列在这条上判「**不满足**」，其依据是 **`你给的` 的硬格**（用户本人原话）—— ⛔ 不是 `我推测的`、⛔ 不是外推、⛔ 不是空格
> 2. ⭐ 那个依据**指向的是这一列自身** —— ⛔ 不是「我觉得这个行业不行」这种笼统判断
> 3. 条件来自通道 3、**原话逐字可引**，且属**不可闭合**类
> 4. ⭐ 它**没有被标 `可能是自我说服`**
>
> ⭐ **⛔「用户在不在场」不再是适用条件。** 用户在场时**同样适用** —— ⭐ 他在场只意味着你**应该顺便问一句**（把回读那句写进一页纸第 ③ 块第 1 条），⛔ **不意味着在他回答之前你什么都不能说**。
>
> ⭐ **方向不对称（⛔ 别当成笔误）**：
>
> | 判成 | 能不能 |
> |---|---|
> | ⭐ **不满足** | ✅ **可以踢出去** —— 因为**踢它的那个事实是硬的** |
> | **满足** | ⛔ **仍然不发通行证** —— 那一格照旧 `gate 待定`、不能排第一 |
>
> > ⭐ **踢掉一个选项，和抬高一个选项，需要的把握不一样。**
> > ⛔ 前者只要**这一条上它确实不行**；后者要**这条底线确实是你的底线** —— **而后面这件事，只有你能确认。**
>
> ⭐ **走这条例外时，结论必须带一句写死的声明**（⛔ 不许省）：**「这个先后建立在一条我从你自己的话里认定、但你还没确认过的底线上 —— 原话是『＿＿』。如果这条不算你的底线，整个先后可能翻过来。」** ⭐ **并写进第四节翻转点**，临界取值 = 二值的「这条底线算不算数」。
>
> ### ⭐ 用户不在场（只有材料，没人可问）—— ⛔ 它和「冷启动」不是同一件事
>
> ⚠️ **框架此前把这两件事混为一谈，于是只有前者有处理。**
>
> | | 用户在不在场 | 条件从哪来 | 降级路径 |
> |---|---|---|---|
> | **冷启动** | ⭐ **在场**，只是第一次用 | 通道 2 | 全部标 `事后重构` → 只跑两套 → gate 只起暴露作用 |
> | ⭐ **用户不在场** | ⛔ **不在场** | ⭐ 只能走通道 3 | 候选条件照提取、照进表，整张表标 **`未经确认`**，⭐ **写在输出最前面** |
>
> - ⛔ **不许因为"用户不在场"就跳过 gate** —— 跳过就回到 `无 gate` 恒触发那个死循环
> - ⭐ **`未经确认` 解除的只有 `无 gate` 这一个标记**（gate 表不再是空的），⛔ **不解除任何别的限制**
>
> ### ⭐ 冷启动（第一次用本模块、没有 `positioning.md`、offer 已在手）
>
> ⚠️ 这种情况下那几条必要条件**必然是"事后重构"** —— 它们是刚刚写出来的。所以：
>
> - ⛔ **不必逐条问"这条是收到 offer 之前写下的吗"**（答案结构性地已知）
> - ⛔ **不许把 2-3 条各跑一套"含它 / 不含它"**（那是二的 n 次方套）。⭐ **一次性按"全部事后重构"处理，只跑两套：含全部 / 一条都不含**
> - ⭐ 一次性说明：**「你这几条是刚写的，所以这一次 gate 只能起暴露作用，起不到约束作用。」** 紧接着给正面价值：**「这一次它的作用是把你的底线写下来；下一次它才开始约束你。」** → 顺手填**第七节入职前存档**，下次它就是事前的了

| # | 必要条件（2-3 条） | ⭐ **哪条通道来的** | 事前写下的？ | **可闭合？闭合上限是什么** | 留在原地 | 选项 A | 选项 B |
|---|---|---|---|---|---|---|---|
| N1 | | 通道 1 / 通道 2 / ⭐ 通道 3（→ 标 `待你确认`，⛔ 确认前既不踢人也不放人） | 是 / **否（→ 标 `事后重构`，仍进 gate，两套都跑）** / 说不清（→ **按事前算**） | 可闭合（上限：＿＿）/ 不可闭合 | | | |
| N2 | | | | | | | |
| N3 | | | | | | | |

⭐ **整张表的表级标记**：无 / ⭐ **`未经确认`**（用户不在场、条件从材料里认定 —— ⛔ 这句话必须出现在一页纸第一段）

每格填「**判定 + 来源标注**」：判定只有三种——**满足** / **不满足** / **有条件满足（写清条件 + 闭合要付什么代价）**；来源标注只有三种——`你给的` / `公开可查` / `我推测的`。

> ### ⛔ Gate 判定格标 `我推测的` 时，不许据此判出局（也不许据此放行）
>
> 第二节横向对照表每格都强制标来源，`我推测的` 不参与排序。**gate 表以前没有这一列，而这一格决定的是谁出局——权重比排序表任何一格都大。**
>
> - ⛔ 标了 `我推测的` → **先把它升级成第五节的一个具体问句**；拿到答复之前，该列在这条上**标 `gate 待定`，留在排序里**，⛔ 不许静默按满足或按不满足处理
> - ⛔ **反方向同样不生效**：不许据一个推测格判「满足」而发通行证。**推测在 gate 上既不能踢人，也不能放人**
> - ⭐ **「不能放人」的执行动作，和「不能踢人」一样写死**（旧版只给了「不能踢人」的动作 —— 留在排序里、标 `gate 待定`；「不能放人」一个动作都没有）：**带 `gate 待定` 的那一列，不能排第一。**
>   - 对称关系：不能踢人 = **留在排序里**；不能放人 = **不能拿第一**
>   - ⛔ 于是 **`gate 未通过` / `有条件满足（待闭合）` / `gate 待定` / `无 gate`（见下一块）四种标记全部不能排第一**，没有例外
>   - **为什么**：不补这条就会出现 —— **必要条件"未知"的那列能赢，"已知违反"的那列反而不能赢**，而两者的差别只是**有没有人去问过**。⛔ 一个奖励"少问一句"的 gate 是反的
>   - ⭐ 解除：那一格从 `我推测的` 升级成 `你给的` / `公开可查` 之后。⛔ **答复截止到了不算解除理由**
> - ⭐ **上游复盘里标 `未验证` 的判据，一律按 `我推测的` 处理** —— 走上面这条完整规则（标 `gate 待定`、留在排序里、不能排第一、进第五节必问项）。⚠️ **「未验证」不是"没问题"，是"没测出来"**；⛔ 只有标 `证实` / `证伪` 的才算 `你给的`
> - ⭐ **`你给的（原话记不清）` 同样走这条路** —— 排序里按 `我推测的` 处理、gate 上标 `gate 待定`；⭐ 但它在第五节里**排最前面**，因为补救成本最低（多半翻一遍聊天记录 / 邮件就能升级）

> ### ⛔ 上面这张表一条都没填时：第四种标记 `无 gate`
>
> ⚠️ **上面三种标记管的都是「某一格没判出来」，而最常见的一种是「一条必要条件都没有」** —— 用户当场给不出，工作区里也没有 `positioning.md`。⭐ **「整个没有 gate」比「某一格没问到」还宽松，旧版却连一个标记都没有** —— **最松的那一种情形反而畅通无阻。**
>
> - **判据是纯字面的**：N1-N3 **一条都没填**。⛔ 不是"填了判不出来"（`gate 待定`），也不是"填了且不满足"（`gate 未通过`）
> - ⛔ **先把三条输入通道都走完再判 `无 gate`** —— ⭐ **通道 3 走过、一句排他性措辞都没找到，才算真的 `无 gate`**
> - ⛔ **它与「分不出来」出口同时成立时：⭐ `无 gate` 优先，⛔ 不走那个出口。** 理由：`无 gate` 管的是**输入缺失**（你还没告诉我底线），那个出口管的是**证据不足**；⭐ **连判据都没有时，谈不上"分不分得出来"**，而且重排出的名次在 `无 gate` 下一列都不能合法排第一。⭐ **执行：第一句照 `无 gate` 的形状说；那三条缺失信息降级成第二段照写（⛔ 不许整块删）；名次那一栏把两条原因并列写清 —— ⛔ 只写"分不出来"会让用户跑去补一堆信息，补完回来发现照样没有一列能排第一，⚠️ 而写下一条底线这件事他今天就能做、且不用问任何人**
> - ⭐ **本次每一列都带 `无 gate` 标记，因而每一列都不能排第一** —— **与另外三种同构**：`gate 未通过` / `有条件满足（待闭合）` / `gate 待定` / `无 gate`，⛔ **四种全部不能排第一**
> - ⭐ **正确输出是那条强结论**（第三节照排、标记照带）：**「没有一列能合法排第一 —— 你一条必要条件都还没写下来。现在该做的不是答复，是先把你的必要条件写下来。」**
> - ⭐ **解除：写下至少一条必要条件，哪怕只有一条。** **一条写下来的底线，比零条强得多；这个标记的作用不是逼你写全，是不让"没写"变成默认放行。** ⛔ 但必须是**一条可判定的条件**（能对每一列答满足 / 不满足）
> - ⛔ **不许因为"就是给不出"就跳过 gate 直接排序** —— 跳过之后，「过了 gate」和「根本没有 gate」在文件里长得一模一样
> - ⚠️ **⛔ 别和冷启动那一支合并**：冷启动管的是「**条件是事后写的**」（有条件，只是时点晚）；这一条管的是「**一条都没有**」。**先用 `无 gate` 逼出至少一条，那一条写下来之后才轮到冷启动分支**

> ### ⛔ 「有条件满足」只对**可闭合**的必要条件成立，且必须有闭合上限
>
> - **可闭合** = 违反之后存在一个**你付得起代价就能消除它**的动作（搬家、换通勤方式、改作息）。⭐ 写下这条时就要写明**闭合上限**，例：「通勤单程 ≤ 一小时；**搬家我接受，但只接受同城，且只接受一次**」
> - **不可闭合** = 没有任何你单方面能做的动作能消除它（岗位没有产出归属、现金依赖期权兜底、汇报线不对）→ **只有满足 / 不满足两档**
> - ⛔ **上限那一格空着的，一律按不可闭合处理**，不许判「有条件满足」
> - **为什么这格不能空**：「有条件满足 → 代价进生活成本 → 合规重入排序」是 gate 唯一的逃逸通道。一笔按摊销年限摊平的一次性代价**吃不掉一个选项的现金优势**，于是那个本该被挡住的选项，会带着一笔小小的扣减重新拿到第一名。**上限是这条通道上唯一的闸门。**
>
> ### ⛔ 但上限只挡「动作的范围」，挡不住「剩余劣势的量级」——再补三条
>
> 上限写全（「同城、一次」）之后，同一条通道会原样复现：搬家闭合 → 代价摊平 → 去吃真实时薪的大幅优势 → 照样拿第一。所以：
>
> 1. ⛔ **真实时薪的分母用「闭合前」的通勤。写死。** 闭合尚未发生；用闭合后会让「违反了你的必要条件」反过来变成优势（分母缩水 → 时薪上升），方向明显是错的。⭐ 「若真的搬了，它的真实时薪会变成 X」写进第四节翻转点，作为**假设**，⛔ 不作为排序输入
> 2. ⛔ **进排序后带 `有条件满足（待闭合）` 标记，且不能排第一**，除非闭合动作**已经完成**（新租约签了 / 已经搬完）。理由：**这条通道进来的选项，它的第一名建立在一个还没发生的动作上。** 这与「留在原地 gate 未通过 → 带标记且不能排第一」是同一条对称约束
> 3. ⛔ **通勤口径写死**（它同时是 gate 判据和分母输入）：**工作日早高峰 · 你实际会用的那种通勤方式 · 单程门到门**，并标来源等级 + 查询日期与时段。**同一份表里所有列必须用同一口径**，口径不同的两列**不可比**
>    - ⚠️ **「你实际会用哪种方式」是一句无人可验证的自述**，所以除了"两种都跑"，还要有**保守缺省**（旧版只有前者，于是一句「我会开车」就能把一列从出局变成第一）：⭐ **换一种方式会改变任何一格 gate 判定时，缺省按更慢的那一种算**
>    - ⭐ 要按更快的那种算，**必须给行为化理由**（「我现在这份工作就是开车通勤」/「小区已有固定车位」这类**已经发生的事实**）。⛔ **不接受可能性陈述**（「我也可以开车」「我打算买车」）—— 与"分母用闭合前通勤"同一条判据：**一个还没发生的动作，不能预支好处**

**出局记录**（有谁出局就写一行，没有就删掉这段）：

- 选项 ×：因 N× 不满足出局。⛔ 不再进入排序。

## 二、横向对照表

> 每格 = **取值 + 来源标注**。来源标注只有三种：`你给的` / `公开可查`（附来源与查询日期） / `我推测的`（⛔ **不参与排序**）。
>
> ### ⭐ `公开可查` 要标**两个**日期（⛔ 只标一个不算标全）
>
> ⚠️ **三个独立案例都撞上同一件事：只标了检索日期，没标材料日期** —— 于是「**当时可不可知**」和「**现在是否属实**」被混成一件事。其中一例直接踩雷：**最关键的那条公开信息，公示于当事人的决策时点之后。**
>
> - ⭐ **① 你查到它的日期**（检索日期）· ⭐ **② 这件事公示 / 发生的日期**（材料日期，⛔ 不许省；查不到就写「材料日期不详」，⛔ 不许拿检索日期顶替）
> - ⭐ **纪律写死**：**材料日期晚于第〇节写的决策时点时，这一格只能用于「今天该怎么办」，⛔ 不能用于「他当时判断得对不对」。** 判据纯字面：**材料日期 > 决策时点** → 触发
> - ⭐ **落表动作**：那一格照填、照标来源，⭐ **但在这一维的比较里按单元格退出**，并在表下写一行：「**这一格公示于决策时点之后，只用于往后怎么办，⛔ 不用于评价当时的判断。**」
>
> ⭐ **`你给的` 的边界写死**：用户直接说的 / offer letter 里的 / **上游复盘里标 `证实` 或 `证伪` 的那些**。⛔ **上游复盘里标 `未验证` 的，一律按 `我推测的` 处理** —— 上游是三态（`证实` / `证伪` / `未验证`），本模块只有两个能落地的档，⚠️ **`未验证` 是"测过了但没测出来"，两个档都不对，所以按更保守的那档走**。⛔ 见到 `未验证` 就当"应该没事"，是这张表最贵的一种错。
>
> ⭐ **offer 条款类的取值（浮动怎么算、几薪、签字费、期权、保证期、汇报线、产出归属），`你给的` 后面必须再加一个后缀**：**`（写进 offer letter）`** / **`（口头说的）`** / ⭐ **`（原话记不清）`**（**听到过、但复述不出对方的原话** —— 它不是 `你给的`（那一档要有可复述的说法），也不完全是 `我推测的`（那一档你根本没听过）；⛔ **排序里按 `我推测的` 处理**，但**必问项排最前面**，因为翻一遍聊天记录就能升级）。⛔ **`（口头说的）` 的现金项在真实时薪分子里按 0 计**，并在第五节配一句「这一条写进 offer letter 了吗？」。⚠️ 这不是第四套标签，是 `你给的` 内部的后缀 —— 没有它，「口头承诺按 0 计」这条纪律**在这张表里没有落点**。
>
> ⭐ **整列现金都是 `（口头说的）` 时，⛔ 不许只留一个 0 就往下走**：必须紧跟一句「这一列的现金按 0 计，**不是因为它低，是因为它还没落纸** —— 拿到书面之后回来重算，这一维很可能整个翻过来」。⭐ **这句话在一页纸上也必须有对应说法**（人话译法见一页纸那张译法表）：⚠️ **一页纸不许出现方法论词汇，而那个 0 不解释，用户在那一页上看到的就是"这家不给钱"** —— ⛔ 恰好是这条纪律要防的那个误读。
>
> ⚠️ **「不参与排序」按单元格生效，不是按整维。** 标了 `我推测的` 的那一格，只让「它 vs 别人」的那几对比较跳过，其余各对照常比。⛔ **不代表这个选项在这一维必然更差**——「查不到」是信息缺失，不是取值低，不许把缺失格当成最差值（也不许当最好值、不许取中位数补）。**只有当关键子项在多数列都是 `我推测的`** 时，才整维退出排序，并在表下写明。
>
> ⚠️ **维度不是必填清单。** 挑选判据只有一条：**这一维在这几个选项上取值不同吗？取值不同才留。** 三列取值几乎一样的维度，删掉。
>
> ⭐ **还在流程中的机会也占一列，列头标 `未成 offer`：进表、⛔ 不参与排序、⛔ 不给名次。** 那一列只填**已经发生的事实**，⛔ 不许按"如果拿到大概会怎样"填（判据见第〇节末尾）。
>
> ### ⭐ 来源独立性：数的是互相独立的来源，不是条数
>
> ⭐ **判据有两问，⛔ 按顺序问，第一问判不出来才用第二问。**
>
> **第一问（⛔ 一个字不改）：两条观察能不能同时错？** 同一个人在同一场对话里说的三句话 = **一个来源**；同一篇稿件被三处转载 = **一个来源**；两个互不通气的人各自说出同一件事 = **两个来源**。⚠️ **这一问有过正面战绩，那条路径原样保留**：五条事实分别追溯到**五个互不相干的对象**（官方登记 / 团队沿革 / 人事时点 / 编制现状 / 两份文本）→ 判「不能同时错」→ ⭐ **判得更硬**。
>
> ⭐ **第二问（新增）：这几条如果错，是"同一个人说错了"，还是"同一个组织事实是错的"？** 前者仍算**一个来源**；⭐ **后者按职能面数算多个独立观测面**。
>
> - ⭐ **为什么必须补**：第一问治得了"同一个人说三遍"，⛔ **治不了"同一个根因在几个不同职能面各露一次"**。⚠️ 实跑里 —— 来自 recruiter 与 HR **至少两个人**、**四个不同职能面**（招聘 / 绩效流程 / 入职安排 / 法务）的四句话被压成**一个来源**，叠加整维退出后**对结论贡献为零**，⭐ **而真值证明它就是决定性的**
> - ⭐ **"职能面"怎么数（字面）**：这几句话分别出自哪个职能环节 —— **同一环节的两句仍算一面，不同环节各算一面**，并**写清是哪几面**（⛔ 只写"多个来源"不算数）
> - ⛔ **第二问 ⛔ 不是放宽保守缺省**：判不出同不同源时**仍然按同源处理**（那条一个字不改）
> - ⭐ 一眼可数的写法：**数"这条取值最终追溯到几个人 / 几份文件 / 几个职能面"**，⛔ 不数"我写了几条"
> - ⛔ 一位面试官口头说了三遍，它仍然只是 `你给的（口头说的）` —— **硬度看落纸没落纸，不看条数**
> - ⛔ 同源的三条检索结果只算**一个** `公开可查`，不许当成"互相印证"。⭐ 写来源要写到**能看出同不同源**的粒度（哪一家、哪一天、原始出处是谁）
> - ⚠️ 「发展空间」「下行风险」两维经常**全部来自同一场面试的同一个人** —— 数成三条"互相印证"会让一个本该是 `我推测的` 的判断看起来像 `公开可查`，**进而混进排序**
> - ⛔ **判不出同不同源时按同源处理**（保守缺省，与「说不清 → 按事前算」同一个方向）
> - ⛔⭐ **利益方向与来源独立性是两件事，⛔ 不许互相顶替**：⚠️ **三个都拿佣金的人说同一句话 —— 既不独立，也同向**，⛔ **两头都要打折**。⭐ **全都带 `（有利益方向）` → 就算它们真的算得上几个独立来源，仍然 ⛔ 不能单独支撑一条"往那个方向走"的判断** —— 独立性解决的是"会不会一起说错"，⛔ **解决不了"会不会一起希望你选那一个"**
>
> ### ⛔⭐ 利益方向：说这话的人，会不会因为你选某一个而得好处
>
> ⚠️ **上面那一整套管的是"这条信息准不准"，⛔ 它管不了"说这话的人希望你怎么选"。** ⭐ **这两件事完全不同**：**一个中间人可以说一句完全属实的话，而那句话之所以被挑出来说，是因为它有利于成交。**
>
> - ⭐ **判据一句话，纯字面**：**这个人会不会因为你做出某一个特定选择而得到好处？** —— **会 → 是**（中间人 / 招聘方 / 猎头 / 拿推荐奖金的在职推荐人）；**不会 → 否**（已离职的人 / 与结果无关的第三方 / 公开登记与公告）
> - ⭐ **标法**：在原有来源标注后面加后缀 **`（有利益方向）`**（与 `（口头说的）` 同级，可叠加）。⚠️ 这**不是第四套标签**，⛔ 不许拿它改写三档枚举
> - ⛔ **不降低它的真实性** —— 他说的可能完全属实
> - ⭐ **但它 ⛔ 不能单独支撑一条"往那个方向走"的判断** —— 需要一个**没有这个利益方向**的来源交叉
> - ⭐ **找不到交叉来源 → 那一格从 `你给的` 降为 `我推测的`**（按单元格退出排序），并 ⛔ **必进第五节**，问法写死：**「这件事我还能问谁核实？」** + 点名一个**没有利益方向**的对象；落到 gate 上同 `我推测的`（`gate 待定`、不能排第一）
> - ⚠️ **⛔ 别改坏：这条只针对"指向一个选择"的判断。** ⭐ **判据仍是字面的：这句话有没有指向一个选择？** —— 「这家更适合你」「那边现在正是好时候」→ **标**；⛔ **中间人转述的客观事实**（面几轮、汇报给谁、几号出结果）**不受影响**，照常按原来的来源标注走
> - ⭐ 它进第四节时证据等级与 `面试口头` 并列，⛔ **不许当成 `公开记录`**

### ⚠️ 整维 / 单格退出排序的记录（有就写，没有就删掉这段）

> ⛔ **旧判据（`我推测的` 过半 → 整维退出）已作废，别再用。** ⚠️ 方向是对的（用可机械执行的判据替换裁量），⭐ **坏的是标定**：**三列表 2 列即过半**，而"任一关键子项是推测即整列计入"让一列极易被判为推测 → **在真实稀疏材料上每一维都出局**。⭐ **更根本的毛病：它对「材料完整度」的敏感性超过了对「证据硬度」的敏感性** —— 一格由**五个互相独立、各自可证伪的来源**撑着的取值，会被同维两个**空格**一起带出局。
>
> ⭐ **新判据只问一件事：这一维里还有没有硬的格。** 三步。

**第一步 · 每一格先定三档（⛔ 是三档，不是两档）**

| 这一格 | 判据（纯字面） | 它缺什么 / 怎么补 |
|---|---|---|
| ⭐ **硬** | 标了 `你给的`（含各后缀）或 `公开可查` | 不用补 |
| **推测** | 标了 `我推测的`（含上游 `未验证`、含 `你给的（原话记不清）`）—— ⭐ **填了，但没有依据** | ⭐ 去**证实** |
| ⭐ **空** | ⭐ **根本没问过 / 没填** —— ⛔ **它不是 `我推测的`** | ⭐ 去**问** |

⛔ **不许把空格静默写成 `我推测的`**（那等于把"没问"包装成"问了但不确定"），⛔ 也不许把推测格记成空格。⚠️ **两者的下一步动作完全不同**：一个是去证实一句已经有人说过的话，另一个是去问一句还没人说过的话。

**第二步 · 每一列在这一维定档（⭐ 一列只数一次）**：关键子项里**至少有一格硬** → ⭐ `可比`；一格硬的都没有但填了推测 → `不可比（推测）`；关键子项**全空** → `不可比（空白）`。

**第三步 · 整维判定：⭐ 数 `可比` 的列，⛔ 不数推测的列**（总列数**含「留在原地」**）

| 这一维里 `可比` 的**列数** | 怎么处理 |
|---|---|
| ⭐ **0 列** | ⭐ **整维退出排序** —— 判据字面：**这一维里没有任何一格是 `你给的` 或 `公开可查`**。⛔ 逐列写进第五节（⭐ **空格问"没问过"、推测格问"要证实"，两种问法分开写**） |
| ⭐ **1 列** | ⭐ **不退出，但本次产生不了任何比较对**。⛔ 不许因此当它不存在 → **必须填下面的「硬证据留档」** |
| ⭐ **≥ 2 列** | ⭐ **保留，只用这几列比**，并明写「**这一维只有 ＿ 列可比：＿＿、＿＿**」；其余各列按单元格退出 |

> ### ⛔⭐ 「有硬格」≠「算得出取值」（⛔ 两件事，别用同一个判据一起判）
>
> ⚠️ **实跑撞到的形态**：真实时薪那一维，**分子有硬格、分母三格全空** —— 按上表这一列判 `可比`（"至少有一格是硬的"字面成立），⛔ **而那个比值根本算不出来**。⭐ **`可比` 判的是「这一列还有没有可追溯的东西」，⛔ 它没有判「这一维的取值算不算得出来」。**
>
> - ⭐ **对"由子项算出来的维"补第二问**（真实时薪 = 分子 ÷ 分母；生活成本 = 几项相加）：**算式里每一个必需输入是不是都有取值？** —— **硬格算有**、**有默认参数兜底的算有**、⭐ **空格 = 没有**
> - ⭐ **都有 → `可比 · 算得出`**：照常算、照常比、照常算差幅
> - ⭐ **有必需输入是空的 → `可比 · 算不出`**：⛔ **不许拿它算差幅**，⛔ **也不许把这一列整个当成空**（那些硬格是真的）—— ⭐ **它落回 `方向确定 · 量级不明`**：方向照用，量级写进第五节
> - ⛔ **不许拿默认参数把空格填满、再宣称"算出来了"** —— ⭐ **兜底参数只兜"问过了但说不清"，⛔ 不兜"根本没问"**
> - ⭐ **定性维（发展空间 / 下行风险 / 既得资产）只问第一问**，⛔ 不必问第二问

- 第 ＿ 维**整维不参与排序**，因为这一维里**一格硬的都没有**
- 第 ＿ 维**只有 ＿ 列可比**（＿＿、＿＿），其余各列在这一维上按单元格退出
- 第 ＿ 维的「＿＿」这一格是 `我推测的` → **只跳过涉及它的那几对比较**，其余照常比

⭐ **整维退出时，⛔ 必须归到四类诊断里的哪一类**（① 真拿不到 / ④ ⭐ **可问而未问** / ② 差幅不过误差带 / ③ 方向相反，见第三节）—— ⚠️ **④ 是最常见、也最常被误并进 ① 的那一类**：**它不是拿不到，是还没问。**

#### ⭐ 硬证据留档（⛔ 可比列 ≤ 1 且这一维里有硬格时，必填）

> ⚠️ **实跑里那一维只有一格是硬的**（追溯到五个互相独立、各自可证伪的来源），同维另外两格是**空的** —— 按旧判据整维出局。⭐ **执行者是靠别的章节手动捞回来的，而框架里没有任何规则要求他这么做。**

| 是哪一格 | ⭐ 硬在哪（追溯到**几个人 / 几份文件 / 几个职能面**，⛔ 不数"我写了几条"） | ⭐ 它单独说明了什么（⛔ 只写这一列自己的事实，⛔ 不许拿它跟空格比高下） | ⭐ 补哪一格就重新可比（写成第五节一个过去式问句 + 该问谁） |
|---|---|---|---|
| | | | |

- ⭐ **它可以进 gate、可以进第四节翻转点、可以进「第 1 名最弱的一维」**，⛔ 只是不进这一维的排序比较
- ⚠️ **gate 与排序维度是两套体系**：一维整维退出，⛔ **不影响挂在它上面那条必要条件的判定** —— 那一格若是硬的，**gate 照判**
- ⛔ **不许因为"这一维不参与排序"就把这一格整个丢掉** —— 丢掉它就是**让材料完整度盖过证据硬度**

## 三、排序结论

> ### ⛔ 上位出口：有一列被硬约束判出局时，⭐ **必须出结论**（⛔ 优先于本模块其余任何一条"不出结论"的规则）
>
> ⚠️ **本模块当前最严重的失败模式不是"判错"，是"拒绝判"。** 一批实跑里六个案例、四种完全不同的真值类型，全部输出**同一形状**：「不排名次 + 数据不够」。⭐ **真值核对：其中四例当时就是可判的** —— 有一例的真值原话是「**几乎不需要推理，只需要不自我说服**」。**根因是三条互锁的机械判据**（`无 gate` + 整维退出 + `未成 offer` 不参与排序），在跨国 / 材料型 / 回溯型输入上几乎必然同时成立，⛔ **任一成立就出不了名次**。
>
> ⭐ **只要有一列被一条二值硬约束判到出局值，就必须出结论** —— 哪怕结论是「**只剩两列，而这两列分不出来**」。⛔ **不许因为别的维整维退出，就把整个结论压成"数据不够"。**
>
> - ⭐ **什么算"二值硬约束"（字面）**：**取到某个值就直接出局、⛔ 没有「有条件满足」这一档**的那类 —— `positioning.md` 的**硬性排除条件** · 已确认的**不可闭合必要条件**判为「不满足」
> - ⭐ **三步照走**：**① 先把出局那句说出来**（「**＿＿出局，因为它在＿＿这条上不满足**」—— ⭐ **这一句本身就是一个结论**）· **② 剩下的列照常比** · **③ 收尾说一句「**＿＿已经出局了，剩下的比不比都不改变这一条**」**（⛔ 前提是被判出局的确实只有那一列）
> - ⛔ **不许把"某一列出局"和"其余维数据不全"合并成一句"数据不够"** —— ⚠️ **前者是结论，后者是缺口；混在一起，用户拿到的是零个结论**
> - ⭐ **它同时管住第二节的维度挑选**：⚠️「取值不同才留」会删掉取值相同的二值维，⛔ **而一个"取到某值就让某列直接出局"的二值维，即使本次取值相同也不许删**
> - ⭐ **验收标准一句话**：**一个"有一列被硬约束判出局、其余维数据不全"的案例，必须能出结论。** ⛔ 再输出一次「数据不够」就是没修好

> ⛔ **带标记的列照带**：`gate 未通过`（留在原地 N× 不满足）/ `有条件满足（待闭合）`（除非闭合动作已经完成）/ `gate 待定`（判定格是 `我推测的`、来自上游 `未验证`、或 `你给的（原话记不清）`，问题已升级到第五节）/ ⭐ `无 gate`（**第一节整张表一条都没填 → 每一列都带**）。⭐ **四种全部不能排第一。**
>
> ⭐ **`gate 待定` 也不能排第一，这是 v0.1.3 补上的。** 旧版只写「推测在 gate 上既不能踢人也不能放人」，却只给了"不能踢人"的动作（留在排序里、标待定），"不能放人"一个动作都没有 —— 结果是**必要条件"未知"的那列能赢，"已知违反"的那列反而不能赢**，而两者差别只是**有没有人去问过**。⛔ 一个奖励"少问一句"的 gate 是反的。
>
> ⚠️ **四条限制加起来可能出现「没有一列能合法排第一」——这不是死锁，是一条强结论。** 照常排完并带上标记，然后写一句：**「没有一列能合法排第一：＿＿（gate 未通过）· ＿＿（闭合动作还没发生）· ＿＿（gate 待定，＿＿ 这条还没问到）。今晚该做的不是答复，是先把 ＿＿ 问出来 / 先把 ＿＿ 落实 / 先回去谈条件。」** ⛔ 不许为了让表好看就悄悄摘掉某一列的标记。
>
> ⭐ **`无 gate` 那一支的收场只有一句**：**「没有一列能合法排第一 —— 你一条必要条件都还没写下来。现在该做的不是答复，是先把你的必要条件写下来（哪怕只有一条）。」**
>
> ⭐ **`gate 待定` 那一支最常见的收场长这样**：**「没有一列能合法排第一 —— 今晚该做的不是答复，是先把『这个岗一周有几成时间在写代码』这条还没问到的必要条件问出来。」**

> ### ⭐ 参与排序的维度为零时怎么写（⛔ 别留空，⛔ 更别自己编一种写法）
>
> ⚠️ **这一件与第四节翻转点都以「名次已经存在」为前提**，而实跑里 **6/6 没有第 1 名**，四个执行者各编了一种写法。写死两支：
>
> - ⭐ **先看上面的「上位出口」**：有没有哪一列被二值硬约束判出局？**有** → ⭐ **先出那条出局结论**，这一件写成：**「＿＿出局（因＿＿这条不满足）；剩下的 ＿＿ 与 ＿＿ 之间没有任何一维可比，所以不出名次。」** ⛔ 不许因为后半句就把前半句也吞掉
> - **一列都没出局** → 照着写：**「本次参与排序的维度是零维 —— ⛔ 不是这几列一样好，是我手上没有任何一维能拿来比。」** ⭐ 紧跟一句缺口：**「要让它变成一维可比，最短的一条是 ＿＿（第五节第 ＿ 条）。」**
> - ⛔ **不许写成「两个都不错，看你自己」**，⛔ 也不许因为"没有名次"就把这一件整块删掉 —— ⚠️ **删掉之后，「比过了但分不开」和「根本没比」在文件里长得一模一样**

> ### ⭐ 加维的停止条件（⛔ 不许无限加下去）
>
> **每次只加一维**（按「取值不同才留」挑），加完立刻判分不分得出来；⛔ **最多加到第三维**。到第三维仍分不出来 → **停**，走「分不出来」出口，并 ⛔ **点名缺的是哪几类数据**，不许只说"信息不足"。逐维写清它为什么没分出来，只有三类：
>
> | 这一维为什么没分出来 | 缺的是什么 | ⭐ 下一步 |
> |---|---|---|
> | ① **整维退出，且真的拿不到**（这一维一格硬的都没有） | **缺数据** | 写成第五节必问项，并说清它可能问不到 |
> | ①b ⭐ **保留但可比列 ≤ 1** | 不算"整维没用" | 走第二节的**硬证据留档**，把"补哪一格就重新可比"写成必问项 |
> | ② **差幅不过误差带** | **不缺数据** —— 这两列在这一维上真的差不多 | 不必补 |
> | ③ **两维方向相反** | **不缺数据，缺的是一次取舍** | ⛔ 不进这里，走下面那个出口 |
> | ④ ⭐ **可问而未问（⛔ 新增，⛔ 不许并进 ①）** | ⭐ **不是拿不到，是还没问** | ⭐ **今天就能做完** |
>
> ⭐ **④ 的判据纯字面**：**这一格有没有一个具体的提问对象（有名有姓的联系人 / recruiter / 某位面试官），且问题写得成一句过去式问句？** **有 → ④**；**没有**（无人可问 / 对方已明确拒答 / 属于「不碰候选人拿不到的信息」那类）**→ ①**。
> ⭐ **④ 的专属措辞写死（⛔ 不许与 ① 用同一句收场）**：**「＿＿这一格不是拿不到 —— 是还没问。今天给 ＿＿ 发一句：『＿＿？』，回信就能填上。」** ⭐ **必须具体到"问谁 + 原话说什么"**。
> ⚠️ **为什么必须分开**：⭐ **把这两种收进同一句话，会把"今天就能做完的事"说成"补不齐"** —— 而这正是本模块自己点名要避免的失败模式。
>
> ⚠️ **三维全是 ② 时，结论不是"分不出来"，而是一条强结论**：**「这几个选项在你选的这几维上确实没有实质差别 —— 差别在你还没写进表里的地方，或者它们对你真的一样。」** ⭐ 此时该做的是**回去加一条必要条件 / 加分条件**，⛔ 不是再加一维。
>
> ### ⭐ 两维都分得出来、但方向相反 —— 独立出口，⛔ 不走「分不出来」

>
> ⭐ **⛔ 「分得出来」包含第三档 —— 这是一处硬断裂，补上**：⚠️ 旧判据字面只认"差幅 / 跨两档"，⛔ **而第三档明写这两样都没有**，于是「一维是第三档、另一维与它方向相反」**两个出口都够不着**。⭐ **第三档算"分得出来"的一种 → 照样触发本出口**（两维都是第三档时同样走）。⛔ **走进来之后不许说"差多少"**，问法照着说：**「『＿＿』这一条上 A 比 B 好是确定的，但好多少我不知道；『＿＿』那一条上 B 比 A 好，差多少我算得出来。这两件事只能保一件，你保哪一件？」**
>
> ### ⛔⭐ 触发不止在维之间 —— **同一维内部两个子项方向相反，同样触发**（⛔ 旧版只有维级）
>
> ⚠️ **实测撞到的形态**：发展空间那一维里，**两个子项各自都有硬格、方向正好相反**。⭐ **执行者自行把它拆成了两维处理 —— 而这一步框架里没写。** 换一个执行者走「整维取中 → 分不出来」，**同样不违规，得到的是相反的产出**。⭐ **同一份材料、同样合规、两个相反结论，差别只在执行者当时怎么裁 —— 这正是本模块最反对的形态。**
>
> - ⭐ **触发判据（字面）**：**同一维内部，有两个子项各自都有硬格**（`你给的` / `公开可查`）**，且方向相反** → ⭐ **与跨维方向冲突同样处理**：走取舍出口，把那句取舍的**原话**记下来当这一次的权重
> - ⛔ **不许"整维取中"** —— ⚠️ **取中会把两个都硬的相反信号抹成一个"分不出来"，信息全丢**
> - ⛔ **也不许执行者自行把它拆成两维** —— 那是**没有判据的自由裁量**
> - ⭐ **取舍问句落在子项自己的说法上，⛔ 不许拿维名去问**（例：「半年内能不能打出一件明确属于我的产出」↔「出错时我担不担责、有没有拒绝权」）
> - ⭐ **记下来时注明它是子项级的**（哪一维的哪两个子项）—— ⛔ 只写维名，下一轮读的人会当成跨维冲突
>
> ⛔ **不许塞进「分不出来」出口** —— 那个出口是给**证据不足**设计的（它要求"先只用 `你给的` / `公开可查` 重排一次 + 点名三条缺失信息"），⚠️ **而这里数据是够的**。两者混用，用户会跑去补一堆补齐了也不改变结论的信息。

  - ⭐ ☐ **他在乎的那几维上没有短板**（⛔ 别漏 —— 上面四种都预设"总有一维最弱"）。⭐ 按 ⓪ 步排除掉他明确降权 / 踢掉的那几维之后**一维都不剩**时用这一种，照着写：「**你在乎的那几维上，我没找到明显的短板。**」+ 一句留痕：「**我没去说 ＿＿ 那一维，因为你说过你不看它。**」

> ⚠️ **为什么这一格必须填**：说出弱点只有两个通道——「相邻名次的差」和「翻转点」，而**一个明显好的选项恰恰两个都不触发**（跟第 2 名差得开，假设动一动也不翻）。结果是**赢面越大的选项，弱点越沉默**。
> ⛔ **但必填不等于必须编一个跨维门槛。** 名次不是综合分决出来的，是**逐维比较 + 决胜维**决出来的，而本模块**没有维度权重**——**没有跨维权衡率，一个非决胜维的取值再怎么跌都不会改变名次**。所以「跌到任何程度都不会」常常就是诚实答案。**任何跨维门槛都等价于偷偷设了一组权重**，那正是「出排序不出综合分」禁掉的东西。
> ⛔ **「最弱」在异质刻度间没有定义**（指数 ±5 和定性三档怎么比？）。挑选判据按顺序：**① 证据最薄的那一维**（`我推测的` 格最多、或整维退出排序的）——一维越薄，第 1 名在它上面的领先越可能是假的；**② 打平时选绝对水平最低的那一维**。⛔ 不许跨刻度换算成一个可比的数再挑。
> ⚠️ 「最弱的一维」**不等于**「跟第 2 名差最少的那一维」——也可能是它自己绝对水平最低、但恰好没人跟它比的那一维。

⛔ 这一节**不写总分、不写星级、不写红绿灯**。

## 四、翻转点声明

> 每条写全五段：**哪个假设 → 现在按什么计入（证据等级）→ 临界取值 → 变成什么样排序会怎么翻 → 要证实它你该问谁 / 查什么**。
>
> **证据等级**（只贴在假设上，与表格里的来源标注是两套东西）：`合同白纸黑字` / `面试口头` / `公开记录` / `自己估算` / ⭐ `未验证`。
>
> ⭐ **`未验证` 专给"上游复盘里问过、但没问出结果"的假设。** 它比 `自己估算` **更该优先进第五节必问项** —— 已经有人试着问过一次并且没问到，说明它要么难问、要么对方在回避。⛔ 但它在第二节的来源标注里一律按 `我推测的`，**不参与排序**。

| # | 假设 | 现在按什么计入 | 证据等级 | ⭐ **临界取值**（取到多少正好翻） | 变成什么样会翻，翻成什么 | 要证实它：问谁 / 查什么 |
|---|---|---|---|---|---|---|
| 1 | | | | | | |
| 2 | | | | | | |
| 3 | | | | | | |

> ⭐ **「临界取值」这一列不许省。** 三点采样只能说「按 0 算会翻」；临界取值说的是「**低于约六成七就会翻**」——这是全表**唯一能直接变成一句谈判 / 提问话术的数字**。
> ⭐ 每个临界取值都要在第五节写成一个**具体问句**（例：「浮动过去两年实际发放的比例是多少？这个口径能写进 offer letter 吗？」）。

⚠️ **一条翻转点都没有时，写在这里，⛔ 不许为了凑数编一条** —— ⭐ **但「因为」后面有两种，⛔ 旧版只给了一种模板，照抄会说反**：

> ⭐ **判据纯字面，一眼分**：**参与排序的维度数 ≥ 2，且每一维的可比列数 = 总列数 → A；否则 → B。**

| | 什么时候用 | 措辞（照着写） |
|---|---|---|
| ⭐ **A · 证据太足型** | 第 1 名在参与排序的每一维上都领先超过该维误差带 | **「本次结论无翻转点：第 1 名在参与排序的每一维上都领先得够开。不必再查了，去谈别的。」** ⭐ 这是一条**强结论** |
| ⭐ **B · 证据太少型**（⛔ 缺席的正是这一种） | **参与排序的东西太少 / 太薄，以至于任何假设怎么变都动不了名次**（只剩一维在比，或每一维都只有一两对可比） | **「本次没有翻转点，⛔ 但这不是因为结论稳 —— 是因为参与排序的东西太少，少到没有什么可翻的。真要让这个顺序动起来，先补 ＿＿、＿＿（第五节第 ＿、＿ 条）。」** ⚠️ 这**不是**强结论，是一条**警报** |

⚠️ ⛔ **不许用 A 的措辞收 B 的场**：**A 说的是"不必再查"，B 说的恰恰是"必须再查"** —— ⭐ **两句话给用户的下一步动作正好相反**，说反一次就把一个"证据不足"的结论包装成了"结论很稳"。

⭐ **零个 offer 形态下（只有第 0 列）**：翻转点改成「**什么变了，你就该开始看外面**」—— 五段照写，最后一段从"排序会怎么翻"改成 ⭐ **取到这个值时「留在原地」就不再过 gate**。⛔ 不许因为"没有排序可翻"就写"无翻转点"完事。

⭐ **也要写「查了也不会翻」的那几条**——它们在告诉你哪些事今晚不必再纠结：

| 假设 | 就算取值反过来，排序也不变，因为 | 名次没变，但**决胜维 / 理由**变了吗 |

## 五、答复前必问项（查不到的都归到这里）

> 查不到的信息**升级为必问项，不猜**。问法一律改成**过去式**——不问「加班多吗」，问「你上周几点下班？上一次连续加班是哪个项目、持续多久？」

| # | 问题（过去式） | 问谁 | ⭐ **它属于哪一类**（① 真拿不到 / ④ ⭐ **可问而未问** / ⭐ 原话记不清） | 为什么问（它挂在哪条翻转点上） |
|---|---|---|---|---|
| 1 | | | | |
| 2 | | | | |
| 3 | | | | |

⭐ **排序写死**：⭐ **`你给的（原话记不清）` 最前** → ⭐ **④ 可问而未问次之**（**今天发一句就有**）→ ① 真拿不到最后。
⭐ **④ 那几条的措辞不同**（⛔ 不许和 ① 用同一句）：**「＿＿这一格不是拿不到 —— 是还没问。今天给 ＿＿ 发一句：『＿＿？』，回信就能填上。」** ⚠️ **把这两类收进同一句话，会把"今天就能做完的事"说成"补不齐"。**

⭐ **`你给的（原话记不清）` 的那几条排在这张表最前面** —— 它不是"要去问一个新问题"，是「**回去把那句话确认成一句可复述的话**」（问法：「你上次说的××，具体是怎么说的？这一条能写进 offer letter 吗？」）。⚠️ 它与 `未验证` 的区别：`未验证` 是**问了没问出来**，`（原话记不清）` 是**问出来了但没记住** —— 排序上待遇相同，但后者多半翻一遍聊天记录 / 邮件就能升级，**补救成本最低，所以先做**。

⭐ **判成 `方向确定 · 量级不明` 的每一维，都必须在这里有一条问量级的具体问法**（⛔ 不许只写「再确认一下这一维」）—— 问法落在**这一维自己的刻度**上。例：真实时薪那一维 →「这两边在这一条上，差的是几成，还是成倍？」；定性三档的那几维 →「这两家在这一条上是差一档还是差两档？各举一件具体发生过的事。」⚠️ **它不是"这一维分不出来所以去补数据"** —— ⭐ **方向已经有了，缺的只是差多少**（判据与措辞见第〇节「⭐ 第三档」）。

⚠️ **口头承诺按 0 计，除非写进 offer letter。** 对每条关键承诺补一句：「这一条写进 offer letter 了吗？」
⭐ 对应第二节的后缀：落纸的标 `你给的（写进 offer letter）`，口头的标 `你给的（口头说的）`。**没有这个后缀，这条纪律在对照表里就没有落点。**

### ⚠️ 问不到，而答复截止已经到了（⛔ 这不是解除标记的理由）

| 该做的 | 内容 |
|---|---|
| ① **标记照带、排序照出** | `gate 待定` 的那列仍然**不能排第一**。⛔ **截止时间到了不算解除理由** —— 时间流逝没有改变任何一格的取值（同理 `有条件满足（待闭合）`：截止到了不等于租约签了） |
| ② **转成"当场就能做的最小验证动作"** | 例：必要条件若是「这个岗一周有几成时间在写代码」→ **翻一遍 offer letter / 岗位描述看它写没写职责构成；再回想面试里对方主动举过的例子属于哪一类**。⚠️ 只能得到 `我推测的` 级别，**⛔ 不解除 `gate 待定`**，但能说明"手上现有的东西指向哪一侧" |
| ③ **明写代价，让用户自己签字** | 「**××这条到现在没问到。你可以选：① 再要一天（多数公司给得起，而且要不要得到本身就是一个信号）；② 现在就答复 —— 那等于你接受『这一条即使不成立，这个 offer 对你也仍然成立』。⛔ 这个字我不能替你签。**」 |
| ④ ⛔ **不许摘标记** | 摘掉之后「问过了并且通过」和「没来得及问」在文件里**长得一模一样** |

## 填表规则 · 每个字段不填会怎样

| 字段 | 不填会怎样 |
|---|---|
| **「留在原地」这一列** | ⛔ **最严重的一格。** 没有它就没有机会成本，没有机会成本就没有翻转点——整张表退化成「在给定的几个 offer 里挑一个」，而「一个都不选」这个真实存在的选项被静默删掉了 |
| ⭐ **自我说服自查那一格** | ⚠️ **通道 3 的 B 组词表恰好就是人自我说服时的句式** —— ⛔ 空着它，从一段"正在给自己找理由"的自述里提出来的"底线"会**原样变成 gate**，⭐ **等于拿一个人的结论去检验他的结论**。⚠️ 而他材料的最后一句常常正是「你说我是不是在给自己找理由」—— ⛔ **框架结构性地答不了**。填了它才有 `可能是自我说服` 这个降级档，也才有那句原样递回去的问话 |
| ⭐ **既得资产那一维 / 沉没成本那一行留痕** | ⛔ **框架里原本一个格子都没有**，且立场上是**反**沉没成本的（唯一的跨期机制摊的是**将来**，最接近的一格是**未来时态**）。⚠️ **对一个已经积累了可保留资格的人，「别被沉没成本绑架」是有害建议** —— 那不是心理包袱，是**一笔换个雇主就要重来的真实资产**。⭐ 判据：「**如果我明天离开，这个东西是留下、还是清零重来？**」 |
| ⭐ **答复截止的第三档 `结构上不存在`** | ⛔ 只有"已知 / 未知"两档时，**"根本没有人在等你答复"会被当成"还没问到"** —— ⚠️ **而没有截止日不是缺输入，它本身就是病灶**：决策被无限推迟，⭐ **而推迟就是选了默认选项**。填了它才会去**自己设一个**，也才说得出那句「**你不定，就是定了「不动」**」 |
| ⭐ **决策时点的第三档 C（在过去做出、至今仍在继续）** | ⛔ 只有 A / B 时，C 只能去凑 B，⚠️ **而 B 写死"这一段不出动作 + 措辞落在下次"** —— ⛔ **于是"今天就该发的那封邮件"被措辞推到了「下次」**。⭐ **B / C 分不清时缺省走 C**（两个方向的代价不对称） |
| ⭐ **可分性判定表里「有没有趋势」那一列** | ⚠️ **「相邻一档视为分不出来」在多年尺度上会系统性抹掉缓慢下滑** —— ⭐ **三年滑三档，每年看都是相邻一档**，于是那三档在输出里一点痕迹都不剩。⭐ **多年尺度要的是斜率，而框架里没有斜率**；判据：**连续两次观察同向 = 一条趋势**（⛔ 不要求三次） |
| ⭐ **「算式里有没有必需输入是空格」这第二问** | ⛔ 只问"这一列有没有硬格"时，**分子有硬格、分母三格全空的那一维会被判 `可比`**，⚠️ **而比值根本算不出来**。⭐ 补了它才分得开 `可比 · 算得出` 与 `可比 · 算不出`（后者 ⛔ 不算差幅、方向照用、量级进第五节） |
| ⭐ **方向冲突表的「维级还是子项级」** | ⛔ 只有维级触发时，**同一维内部两个都硬、方向相反的子项没有归宿** —— ⚠️ **执行者要么自行拆维（框架里没写这一步），要么整维取中（把两个都硬的相反信号抹成"分不出来"）**。⭐ **同一份材料、同样合规、两个相反结论，差别只在他当时怎么裁 —— 这正是本模块最反对的形态** |
| ⭐ **`（有利益方向）` 后缀** | ⛔ 框架只管"这条信息准不准"，⚠️ **完全没有位置记录"说这话的人希望你怎么选"** —— **一个中间人可以说一句完全属实的话，而那句话被挑出来说是因为它有利于成交**。⭐ 标了之后：⛔ 不降低真实性，⭐ **但它不能单独支撑一条"往那个方向走"的判断**，找不到无利益方向的交叉来源就降为 `我推测的` |
| ⭐ **「最弱的一维」的 ⓪ 排除步** | ⛔ 没有它，会挑出一个**正确但无用**的答案：那一维确实最弱，⚠️ **而用户开头就明说过他不关心它** —— ⭐ **一个他不在乎的维度上的短板，不是他的短板** |
| ⭐ **`待你确认` 例外的判据（那一格的取值有多硬）** | ⛔ 判据写成"用户在不在场"时，⭐ **拿"他没确认这是他的底线"去挡住"他自己说了这件事不成立" —— 挡错了对象**：⚠️ **`待你确认` 标的是「条件」那一栏，⛔ 而旧规则拿它否掉了整行，连「这一列没有 ××」那个硬事实一起否掉了**。⭐ **方向不对称别弄反**：判「不满足」✅ 可以踢；⛔ 判「满足」仍不发通行证 |
| **必要条件（N1-N3）** | 没有 gate。所有取值变成可互相补偿的权重，于是「它发展空间最好，所以通勤远一点也认了」这类当场改规则的事一定会发生 |
| **通勤（往返）** | 真实时薪算不出来。**这是「名义薪资高但真实时薪更低」最常见的来源**，漏掉它，排序基本上就是在比名义数字 |
| **浮动的历史兑现率** | 浮动按承诺值全额计入 → 高浮动的那列被系统性高估。**填不出来不是问题**，按承诺值 / 按七折 / 按 0 各算一遍，看排序翻不翻——翻了它就是一条翻转点 |
| **一次性搬家 / 租房成本** | 这笔钱会整个消失。它常常刚好抵消掉一个选项的现金优势，是最容易漏、且漏掉后果最大的一格 |
| **来源标注（每一格）** | ⛔ 推测和事实混在一起，排序看起来精确，实际上不知道建立在什么上。**一个没标来源的取值和一个编出来的取值无法区分** |
| **发展空间的各子项** | 这一维全落到 `我推测的` → **它不参与排序**。这不是 bug，是设计——但你要知道它出局了，而不是以为它已经被考虑过 |
| **必要条件的「事前写下的？」一格** | 事后重构的必要条件会被当成事前的用，于是门槛可以被当场裁剪成刚好放行你本来就想去的那家——**gate 的约束力就是这么消失的** |
| **「事后重构」的两套排序对照** | ⛔ **这一格是 gate 上最大的洞。** 这一格无人可验证，而且**说谎方向单一有利**：想去的那家违反了一条不可闭合底线时，答一句「现在才想的」就能把它清空。两套都跑，是把「结论有多依赖这句话」摆到台面上的唯一办法——⛔ 不填等于让一句无人可验证的话直接决定谁出局 |
| **gate 判定格的来源标注** | 「A 满足 N1」可以整格是 agent 推测的，且**不可见**——而这一格决定的是**谁出局**，权重比排序表任何一格都大 |
| ⭐ **gate 表整张空着时的 `无 gate` 标记** | **「整个没有 gate」比「某一格没问到」还宽松，却一个标记都没有** —— 于是最松的那一种情形畅通无阻，某一列拿了第一。带上它 → **每一列都不能排第一**，正确输出是「先把你的必要条件写下来（哪怕只有一条）」。⛔ 不许因为"就是给不出"就跳过 gate 直接排序 |
| ⭐ **方向冲突那张表的「本次取舍（用户原话）」** | 两维都分得出来但方向相反时，**框架没有名次的产生算法** —— 执行者只能把它塞进「分不出来」出口，⚠️ **而那个出口是给证据不足设计的，措辞上与"证据充足、方向冲突"完全无法区分**（用户会跑去补一堆不改变结论的信息）。填了它，名次才有来源；⛔ 空着又出了名次 = 权重被藏进了公式 |
| ⭐ **分母里的「出差」一行** | 与通勤同性质的一笔真实时间被整个漏掉。⛔ **报销的是钱，不是时间**；「私有化交付 / 现场支持 / 驻场」这类岗位描述**本身就是证据**，看到它还按 0 计，真实时薪就是高估的 |
| ⭐ **`未成 offer` 那一列** | 「另一家还在面」这个**很可能最常见的形态**在表里消失 —— 而**「等不等它」本身就是今晚要决策的事**。⚠️ 反过来把它排进名次也错：那等于给一个还不存在的东西发名次 |
| ⭐ **agent 自加参数的来源等级** | 实跑里执行者临时编了一个折算系数，**而它决定了唯一参与排序那一维的判定** —— 一个没进口径表、没标等级、没被采样的数字独自决定了结论。⚠️ 方向声明不能替代等级：**方向管采样怎么采，等级管要不要采** |
| ⭐ **整维退出的「有没有硬格」判据** | ⚠️ **旧判据（`我推测的` 过半）在真实稀疏材料上让每一维都出局** —— 三列表 2 列即过半，且"任一子项推测即整列计入"。⭐ **更根本的毛病：它对材料完整度的敏感性超过了对证据硬度的敏感性** —— 一格由五个互相独立来源撑着的取值，会被同维两个**空格**一起带出局。现在：**格分硬 / 推测 / 空三档；整维退出的判据是"这一维一格硬的都没有"；≥2 列可比就保留、只用这几列比** |
| ⭐ **「空格」与「推测格」的区分** | ⛔ 两者被同等对待时，**"没问过"会被包装成"问了但不确定"** —— ⚠️ 它们的补法完全不同：一个去**问**，一个去**证实** |
| ⭐ **硬证据留档那张表** | 可比列 ≤ 1 但这一维有硬格时，那一格会跟着整维一起消失。⚠️ **实跑里执行者是靠别的章节手动把它捞回来的，而框架里没有任何规则要求他这么做** |
| ⭐ **「上位出口」（有列被硬约束判出局 → 必须出结论）** | ⛔ **本模块最严重的失败模式：不是判错，是拒绝判。** 六个案例、四种真值类型全部输出「不排名次 + 数据不够」，⭐ **而真值显示其中四例当时就是可判的**。空着它，一条已经成立的出局结论会被"别的维数据不全"压成"数据不够" |
| ⭐ **「可问而未问」这一类诊断** | ⛔ 它被并进"缺数据"时，**"今天发一句话就有"会被说成"补不齐"** —— 而这正是本模块自己点名要避免的失败模式 |
| ⭐ **gate 的第三条输入通道 + `待你确认`** | ⚠️ **旧版两条通道都要求用户在场** → **所有材料型输入最多只能走到 `无 gate`**，⭐ **它对所有此类输入给同一结论，与一条坏掉的规则无法区分**。⭐ `待你确认` 是"提取 = 替用户立法 / 不提取 = 有信息却判一条都没有"这个两难的解 |
| ⭐ **`无 gate` 与「分不出来」的优先级** | 两者要求相反（一个要排序照出，一个是唯一允许不出排序的出口），⛔ 没有裁决句时执行者只能自己挑。⭐ **`无 gate` 优先**：它管**输入缺失**，那个出口管**证据不足**，**连判据都没有时谈不上"分不分得出来"** |
| ⭐ **「公开可查」的材料日期（第二个日期）** | 「**当时可不可知**」与「**现在是否属实**」被混成一件事 —— 实跑里一例直接踩雷：**最关键的那条公开信息公示于决策时点之后**，⛔ 它只能用于"今天该怎么办" |
| ⭐ **前置声明栏** | **雇佣形式**这类既不是维度、也不是参数的输入没有容器 → 它散在正文一句话里，**下游每一维各自解释一遍**。⛔ 它标 `我推测的` 时，**一个推测的前提能同时污染好几维，比一个推测的取值更贵** |
| ⭐ **全 remote / 住处未定时的通勤与租金** | ⚠️ **住处取决于租金、租金取决于住处 —— 两格互为输入**。⛔ 只标一格会让另一格看起来是硬的；⛔ 全 remote 时编一个通勤时间更糟 |
| ⭐ **跨时区错位（分母）/ 可计费周数（分子）** | 两件真正吃时间 · 吃钱的事在枚举里没有位置：跨时区错位与通勤同性质（**你为这份工作实际支付的时间**）；无带薪假时**分子按全年算就是高估** |
| ⭐ **可分性判定的第三档 `方向确定 · 量级不明`** | ⛔ 只有"分得出来 / 分不出来"两档时，**"这一维上 A 优于 B 是确定的、只是不知道差多少"和"两列真的差不多"在输出里长得一模一样** —— ⚠️ **而两者的下一步动作正好相反**：后者该换下一维，⭐ **前者这一维已经有结论了，缺的只是量级**（而它若是决胜位置，方向本身可能已经够用）。判据：**这一维上有没有一条 `你给的` / `公开可查` 的事实能确定谁优于谁** |
| ⭐ **材料一致性自查那三行** | ⛔ **框架里原本没有任何位置处理"材料自己前后对不上"**（典型：一处事件日期晚于答复截止日）→ 执行者只能去借「两套都跑 + 显式声明」，⚠️ **而那个模式是为"外部事实不确定"设计的，不覆盖"材料自我矛盾"**。空着 = 没跑过；⛔ 删掉之后「跑过且无冲突」和「根本没查」长得一模一样 |
| ⭐ **一页纸第 ③ 块的 A / B / C 措辞选择** | ⛔ 只有「这几天该做什么」一种措辞时，**回溯 · 复盘场景用不了它** —— 执行者只能自己定口径，多半写成「你当时应该……」。⚠️ **那句话产出零个可执行动作**（那个时点已经过去了）。⭐ B 的措辞必须落在"下次"：**回溯的用途是让下一轮不再漏，不是让人后悔** |
| ⭐ **`未成 offer` 三判据的 `判不出来` 一档** | ⛔ 只有 `成立` / `不成立` 时，**"我没人可问"会被读成"它不值得等"** —— ⚠️ **"没人可问"说的是你的处境，不是那家公司的** |
| ⭐ **零个 offer 形态下三件产出的替代形态** | 六件必需产出里**三件失去对象**，而模板对它们都写着「不许留空」→ 执行者要么留白违规，要么**硬编一个不存在的名次** |
| ⭐ **「本次没有第 1 名」这个合格答案** | 三种旧答案**全部预设存在第一名**，而实跑里 **6/6 都没有** → 这一格被空掉，或四个执行者各编一种写法 |
| ⭐ **「无翻转点」的 B 型措辞（证据太少）** | 只有 A 型（证据太足）时，**一个"证据不足"的结论会被包装成"结论很稳"** —— ⚠️ **两句话给的下一步动作正好相反**（"不必再查" vs "必须再查"） |
| ⭐ **「来源独立性」的第二问** | 第一问治得了"同一个人说三遍"，⛔ 治不了"**同一个根因在几个不同职能面各露一次**" —— 实跑里四个职能面的四句话被压成一个来源，**对结论贡献为零**，⭐ 而真值证明它就是决定性的 |
| ⭐ **来源独立性** | 同一场面试同一个人说的三句话被数成"三条互相印证的观察" —— 一个本该 `我推测的` 的判断看起来像 `公开可查`，**进而混进排序**。⭐ 判据：**它们能不能同时错** |
| ⭐ **`gate 待定` 那一列的"不能排第一"** | **必要条件状态"未知"的那列会拿第一，而"已知违反"的那列（留在原地）反而不能拿** —— 于是"没问到"比"问到了并且没通过"更有利，差别只是**有没有人去问过**。⛔ 一个奖励"少问一句"的 gate 是反的 |
| ⭐ **上游 `未验证` 的判据按 `我推测的` 落表** | 上游三态被压回两态：「某判据：未验证」按字面就是"来自面试复盘" → 判 `你给的` → **参与排序**。⚠️ **「未验证」不是没问题，是没测出来**——上游花力气把它和 `证伪` 分开，就是为了不让它在这里被当成通过 |
| ⭐ **`你给的` 的 `（写进 offer letter）` / `（口头说的）` 后缀** | 「口头承诺按 0 计」这条纪律**在这张表里没有落点** —— 一句口头承诺和一行合同条款长得一模一样 |
| ⭐ **先读 `positioning.md` 这一步** | agent 从零重问必要条件 → **一条几周前手写的真·事前条件，被重问一遍就变成"今天才说的"，降级成 `事后重构`**。另外 `positioning.md` 的**硬性排除条件**会整类丢失（它的语义是短路：命中即出局，没有「有条件满足」这一档） |
| ⭐ **通勤方式改变 gate 判定时的保守缺省** | 只有"两种都跑"、没有保守缺省时，用户一句「我会开车」就能把一列**从出局变成第一**。缺省按更慢的那种算；要用更快的须给**行为化理由**（已经发生的事实），⛔ 不接受「我也可以开车」这类可能性陈述 |
| ⭐ **联网检索那一行 / 三点采样那一行** | 「没查过」和「查了没查到」长得一样；「最小路径的初版排序」会被当成"已经采样过的定版" |
| **误差带的「声明于第几轮」一列** | 「⛔ 不许排完序再回头调」在机械层面**无痕**，于是它只是一句话。**一个从来没被观测到「先声明」过的先后约束，和一个没有这条约束的模块无法区分** |
| **误差带被覆盖时「凭什么收窄」一列** | 覆盖误差带成为一个**无下限、无论证义务**的口子。实测：结构完全同构的样本上，±5 → A 第 1，±1 → B 第 1——**换掉的是名次，不只是决胜维** |
| **「有条件满足（待闭合）」标记** | 从 gate 逃逸通道进来的那一列**无标记、无限制、可以裸奔拿第一**——而它的第一名建立在一个**还没发生的动作**上。模块给「留在原地」写了对称的限制，这一列过去没有 |
| **通勤口径（早高峰 / 哪种方式）** | 它同时是 gate 判据和真实时薪分母输入。不定义死，borderline 样本（地铁 65 分钟 / 开车 48 分钟）可以在 **gate 门口就被绕过去**；两列口径不同时整张表不可比 |
| **交互采样那一格** | 只做单参数逐个变动会**漏掉交互项**：「浮动按 0」单独不翻、「摊销按 1 年」单独也不翻，两者同时成立可能翻掉名次 |
| **必要条件的「闭合上限」一格** | ⛔ **gate 唯一的逃逸通道就开在这里。** 空着 = 任何违反都能被判「有条件满足」，代价摊进生活成本后**吃不掉现金优势**，那个本该出局的选项会带着一笔小扣减重新拿第一。空着就按不可闭合处理 |
| **估算误差带那张表** | 「差幅小于误差带就换下一维说」这条规则失效——因为你可以在看到结果之后再挑一个刚好合意的误差带。同一份数据取 ±1 和取 ±5 会给出**两条不同的决胜维、两套不同的理由** |
| **第 1 名最弱的一维** | ⛔ **赢面越大的选项，弱点越沉默**：它跟第 2 名差得开（差异那节只会夸它），假设动一动也不翻（进不了翻转点）。少了这一格，第 1 名在这份表里就是没有缺点的 |
| **翻转点** | 你拿到的就只是一个结论，不知道它错多少会变。**计算器给你一个数，决策工具告诉你这个数错多少结论才会变**——少了这一节，这张表就只是个计算器 |
| **翻转点的「临界取值」一列** | 你只知道「按极端值算会翻」，不知道**翻在哪儿**。临界取值是全表唯一能直接变成一句谈判 / 提问话术的数字，漏掉它 = 拿着一张表却问不出一个具体问题 |
| **决策分离结论** | 「这家公司会不会成」和「我要不要去」被混成一个判断。这两件事经常答案相反 |
| 口径与假设那一节 | agent 下次还得从头猜一遍你的口径。填了它，下次直接命中 L1 |
| 加分条件 | 影响不大。**加分条件本来就不参与出局判定**，它只在排序解释里当补充说明 |
| 入职前存档 | 半年后你会记不清当初赌的是什么，只会记得结果 |
