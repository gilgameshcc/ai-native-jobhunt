# 单页校验 checklist

> 配套 [SKILL.md](../SKILL.md)。本表存工作记录，**不附在对外简历中**。每项填已通过/有问题/未检查及证据；不能预先打勾。

- 最终文件路径与版本/修改时间：
- 导出方式与实际页数证据：
- 渲染/截图路径或人工查看记录：
- 最终文件抽取/复制文本路径或核对记录：

| 检查 | 状态与证据 |
|---|---|
| 最终 PDF 实际只有一页；仅看预览则写「最终 PDF 待核」 | |
| 正常阅读比例下字可读，无裁切、重叠、乱码和孤立标题 | |
| 抽取/复制文本的姓名、联系方式、公司、日期、数字与内容稿一致 | |
| 所有段落完整，阅读顺序正常，无末行丢失或不可复制关键文字 | |
| 无占位符、建议假设、内部标记和校验备注 | |
| 修改后检查记录仍对应这份最终文件 | |

可用现有 `tools/md2pdf` 或编辑器导出，不要求安装新工具。工具退出码 0 和行数估算都不能替代上述检查；工具失败可切现有编辑器。溢出优先精简冗余，保留有用证据与事实限定；不靠不可读字号、裁切或删掉必要事实换一页。

缺渲染/文本读取能力时，写清未检查项，并请人工打开最终 PDF、按实际大小查看、复制文字至纯文本核对。完成后将同一最终版本交 [独立审查](定制白名单自查表.md)。
