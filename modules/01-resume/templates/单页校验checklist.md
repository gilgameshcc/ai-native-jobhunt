# 单页校验 checklist

> 见 [`SKILL.md` 第四步](../SKILL.md#第四步--单页硬约束--视觉复核)。**两条路径任选一条，效力相同**——不是工具路径优先、no-code 路径降级。

## 路径一：工具校验

- [ ] 跑了 `node tools/md2pdf/md2pdf.js <定制稿.md> <输出.pdf>`
- [ ] 退出码是 `0`（单页通过）
- [ ] 打开生成的 PDF 肉眼确认排版没有明显问题（字体渲染、表格错位这类工具报告不了的视觉问题）

**退出码不是 0？**
- `1`（溢出）→ 回 [`SKILL.md` 第三步](../SKILL.md#第三步--定制白名单四处改别的都算违规) 用白名单里"删条目/调顺序"精简，⛔ 不许靠缩字号压行距硬塞
- `2`（环境问题）→ 直接切路径二，不是失败

## 路径二：no-code 校验法

- [ ] **第一步·估算**：数了定制稿总行数（含每条 bullet 单独算一行、含分节间距），落在约 45-55 行区间内（常规 10-11pt 字号下 A4 单页的经验区间）
- [ ] 明显超出这个区间的，已经先精简过一轮
- [ ] **第二步·打印预览人工确认**（⛔ 不可省，第一步只是筛查）：已经把定制稿转成能"打印预览"的格式（Word / Google Docs / 任意支持打印预览的编辑器），并用系统打印预览功能看过渲染后的实际分页
- [ ] 打印预览显示确实是单页（不是"估计应该是单页"）

## 两条路径共同的收尾

- [ ] 已把这次校验结论（哪条路径、单页与否、如果溢出精简了什么）记进定制稿末尾的一行备注
- [ ] 已在 `ledger.md` 补登记（见 [`SKILL.md` 第五步](../SKILL.md#第五步--输出与台账登记)）

> ⛔ **只做了「估算」就标记通过 = 没有真的做完这一步。** 这是「不对劲的时候」表里点名的一条常见失效模式——估算合格不等于视觉上不溢出。
