# `resume` · 简历整理

> **v0.2.0** · M1：把真实经历变成有针对性、可读且经过审查的一页简历。

Agent 可以主动提炼优势、重写句子、建议不同叙事和补证路径；事实池约束的是经历真实性，不是表达方式。你不用逐句批准可逆的文字编辑。

## 它做什么

输入你的经历素材或 `facts.md`，可选目标 JD；产出定制 markdown、最终 PDF（具备导出条件时）、独立审查与单页校验记录，以及台账登记。直接把 [SKILL.md](SKILL.md) 交给 agent。

- **事实保持**：允许重写、合并和相关性取舍；角色、时间、数字精度、责任与结果归因必须有事实依据。待核实建议放在简历之外。
- **主动建议**：给出最有价值的修改、原因、可直接使用的改写，以及需要你补充的证据；不满足于换关键词。
- **最终交付**：核对真实分页、可读性、文本完整性，并交独立 subagent 审查。没有对应能力时如实列出未完成检查，提供人工退路。

## I1 三问

**① 单独用行不行？** 可以，几段经历和一句目标方向就能开始。

**② 依赖谁？** 沿用 [M0 的事实池契约](../00-workspace/templates/facts.md)；可选 [JD 定级](../03-company-analysis/jd-triage/README.md)，无需先跑其他模块。

**③ 缺上游退化成什么？** 散乱经历由 agent 整理成事实池草稿；无经历时集中询问最少材料并给骨架，不编简历。无 JD 产出通用基础稿。无渲染/独立审查能力仍交内容稿和具体待检查项，不宣称已完成最终验收。

## 不做什么

不编经历、不把参与升级为主导、不擅自提高数字精度；不把推测写入正式简历；不通过缩成难以阅读的小字或裁切换取一页。对外发送沿用用户授权范围。
