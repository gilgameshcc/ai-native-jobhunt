# 06-positioning · 求职方向的双环复盘

> **v0.1.5** · 纯 markdown，零可执行依赖 · 准入条件只有一条：你手上有一个能读写本地文件的 agent

投了一批，没什么回音，你想知道问题出在**表述**、出在**阈值**，还是出在**方向本身**。

或者更麻烦的那种情况：一轮跑完，你隐约觉得自己该找的可能根本不是原来那个东西，但说不清是真信号还是自己想多了。

也可以尚未开始投递：agent 按你的能力、想解决的工作问题和地域限制主动发现 AI 原生机会；之后按约定周期总结反馈、复核目标、提出下一步。

这个模块把这两件事**分成两个环来做**，因为它们要的过滤器正好相反。

**它产出**：仅探索时给主动机会探索卡、核实缺口、下一步与下次日期；有历史材料时附周期复盘，按证据输出可做的双环判断、`discoveries.md` 登记和符合门槛的 `branches.md`，不为了凑齐产物强行开分支或改定位。

---

## ⚠️ 先说清楚：两个环，不是两个步骤

| | 它改什么 | 例子 |
|---|---|---|
| **收敛环**（执行层） | **目标不变，做得更准** | 改事实池里那件事的讲法 / 改渠道·城市·薪资档的配比 / 改定级阈值 |
| **发散环**（结果层） | **目标本身可能换** | 换参照系 / 开一条新的探路分支 / 关掉一条线 / 产出的根本不是一个岗位 |

**为什么不能合并成一个环**：收敛环的核心纪律是「最小样本门槛 + 默认不动」——它存在的全部意义就是**防止你被一两次拒绝就改定位**。而「投着投着发现新可能性」的信号**天然是单次的、不重复的、看起来像噪声的**。

**同一个循环、同一套阈值，一定会把它当噪声滤掉。收敛环的防过拟合纪律，恰好会杀死发散环需要的信号。**

这是本模块最重要的一条设计判断，`SKILL.md` 里有专门一节写它。**两个环唯一的接口是：登记免费、不设门槛；门槛只加在「登记 → 开分支」这一步。**

## I1 三问

**① 单独用行不行？**

行。**有求职画像即可开始主动探索；有投递台账则同时做双环复盘**，不需要读过本仓库任何其他文档，也不需要先接受这里的任何方法论。把 `SKILL.md` 整份交给你的 agent，说一句「按这个帮我复盘一轮」就能开始。

**② 依赖哪些模块的输出？**

四个可选上游，一个都不是硬必需：

| 上游 | 谁产的 | 给这个模块什么 |
|---|---|---|
| `ledger.md`（台账） | 所有模块 / 你自己 | ⭐ **数据量最大的一条输入**。投递漏斗信号、对方回应原话、反向吸引标记全在这里 |
| `interviews/<company>-<date>.md`（当天复盘） | `04-interview` | 面试反馈：红旗绿旗实测三态 + ⭐ **溢出栏**（发散信号 N4 的唯一采集点） |
| `runs/<date>-review.md`（每日 review 卡） | 投递执行模块 | 跳过原因分布、风险信号——让漏斗信号多一层粒度 |
| `jobs/<batch>.md`（一批待评估岗位） | 投递执行模块 / 你手工贴 | 市场语料：JD 高频词与结构变化，是 N1 / N6 两类信号的唯一来源 |

**③ 缺了上游会退化成什么？**

- **没有投递台账**：从工作方向、已有能力证据、地域和必要条件开始发现机会；不编造漏斗结论。散记录由 agent 整理，有多少先处理多少，是否修订按各条规则的证据门槛决定。
- **没有 JD**：沿产品、雇主、团队和具体职位查找，读取后进入已有 `jobs/` 与定级流程；不要求用户先准备岗位库。只有公司线索时先观察，不算在招。
- **缺 `interviews/`**：发散信号 N4（溢出）整类停用，且会明说停用了。⭐ **红旗绿旗的校准失去对照基准 → 具体做什么**：手工列 3 个"当时想验证的点"顶上，整段标 `事后补的基准，可信度低`，**不喂给收敛环的决策 ① ②**，报告里写成「本轮红旗绿旗校准不可判」（口径与 `04-interview` 缺上游评估时一致）
- **缺 `jobs/`**：已有语料侧的 N1 / N6 暂不可判；主动检索仍继续，新语料积累后再按各自门槛判断
- **缺 `runs/`**：漏斗信号只能靠台账重建，粒度变粗（拿不到「跳过原因分布」）——**它会告诉你少了哪一层，而不是假装分析完整**
- ⭐ **缺的不是文件而是「字段」时，性质完全不同**：**渠道** / **用的是哪一版材料** / **级别** / **这条岗位是怎么进来的** / **JD 里有没有写学历门槛** —— 这几个只能在事情发生的当下记。⛔ **没记 = 过去那一段永久不可判，再攒也不会有**；它会告诉你**从现在开始记什么**，并明说**过去那部分补不回来、别去补**（凭记忆补出来的会和真数据长得一模一样）
- ⭐ **不能联网**：本模块主链路**不依赖**联网，照跑。变的是 `公开可查` 这一整档不可用（本该查的一律标 `我推测的` + 「因无法检索而未核实」）· 来源独立性核对**退化成保守口径**（判不出就合并计 1）· 报告顶部写一行「本次无公开检索能力」
- **缺 `positioning.md`**：「面试官关注点与预设定位不符」这类信号**没有参照物，变成不可判定**。⭐ **不可判定之后不丢弃**：全部按 N2（错配）登记进 `discoveries.md`，注明「无定位参照，本轮只登记不判定」，等定位文件建起来之后回头重判——**判定可以补，原话补不回来**

> ⭐ **停用的信号类别必须显式列出来，写成「这类信号现在看不出来，不是不存在」。**
> 这是本模块最容易被做坏的地方：用户跑出一堆空栏，会以为是自己没做对。详见 `SKILL.md` 的「最小可见量级」。

## 不做什么

- ⛔ **不做职业规划咨询。** 发散环只负责**把可能性摆上台面 + 给出证伪方式**，不替你决定要不要转行、要不要去某个行业
- ⛔ **不预测行业前景。** 「这个方向未来三年怎么样」不是这个模块能回答的问题，也不是它需要回答的问题——它只报告**你自己的数据里正在发生什么**
- **网站操作细节复用投递模块的只读发现路径。** 本模块负责按用户画像决定找什么、为什么找和何时复核，不新建聚合站或长期爬取系统
- **不把小样本解读为整体趋势。** 按证据保留原定位，仍可建议低成本研究、登记线索；独立过门槛的单点建议按 SKILL 规则处理
- ⛔ **不把发散环变成无差别大量投递。** 三条防失控纪律（配额 / 证伪判据 + 截止期 / 成本上限）是硬的，**没有证伪判据的分支不许开**
- ⛔ **不把「量不够」和「字段没记」写成同一种空栏。** 前者再攒攒就有，后者**攒到天荒地老也不会有** —— 对第二类说"再攒攒"是**错的建议**
- ⛔ **不拿「回溯提示」去追责。** 它只回答一个问题：**下次这类事发生时提醒我做什么**
- ⛔ **不写死任何阈值。** 样本门槛、重复次数、配额、截止期全部参数化，且每个都标来源等级（`实践校准` / `默认建议值` / `纯占位待校准`）

- 仅改判据表述与兜底例外，未动 `discoveries.md` / `branches.md` 契约（§9 / §10 最小字段不变）→ **patch**。

### v0.1.4（依据一次**合成回溯测试**的修订）

> **来源：一次合成回溯测试** —— 8 个案例，框架在**不看真值**的情况下跑完，只看它自己产出的报告里**哪些格填不出来 / 填得自相矛盾**。下面每条都是"执行者被迫临场判一个，而框架没给判据"。

- ⭐ **P0 · 空栏拆成两种：「量不够」与「字段没记」**（3 个案例复现）。
  **为什么改**：报告里出现空栏时，用户看到的都是"差多少"，于是**一律理解成"再攒攒就行"**。⛔ 但有一类空栏是**永久不可判**的 —— **渠道** / **用的是哪一版材料** / **级别** / **这条岗位是怎么进来的** / **JD 里有没有写学历门槛**，这些只能在**事情发生的当下**记，**攒到天荒地老也不会有**。⭐ **对这一类，「再攒攒」这句安慰是错的建议。** 现在：SKILL 新增「空栏必须分成两种」（含一条比清单更耐用的判据：**这个字段是不是只能在当下记**），并要求对第二类输出三件事 —— **① 永久不可判（不是本轮不够）② 从现在开始记什么 ③ ⛔ 过去那部分补不回来、别去补**（凭记忆补出来的字段会和真数据长得一模一样，然后在下一轮被当成 `你给的` 用掉）；报告模板拆出**「字段体检」**表 + 「可判？」栏三态 + 第五节按两类分开列。
- ⭐ **P0 · 两条门槛冲突写死优先级**。某个信号的「最小可见量级」说**不可判**，而它的开分支门槛说**够了** —— 两条门槛给出相反答案，原文没写谁优先。现在：**最小可见量级优先**。理由：前者管「**这类信号现在看不看得出来**」，后者管「**看出来之后要不要行动**」，**前者不过，后者根本不该被评估**。⛔ 不许拿"次数够了"越过它 —— 登记是零门槛的，次数在量级不足时本来就能被噪声凑出来。
- ⭐ **P0 · 补上「门槛是逐条的」的反方向**。原文只写了正方向（逐条过门槛才触发），没写**整轮样本体检不达标、但某一条自己的门槛已经过了**时怎么办 —— 实测里这条被"整轮走 ⑤"一起压掉了。现在：**那一条仍然输出**，带标注「本轮整体样本不足，这条是单点触发，谨慎采纳」。**理由**：那条门槛的分母不是本轮投递总数（3 家不同公司问了同一件事，不因为你这轮只投了 12 条而变弱），**一起压掉等于让样本量惩罚一条本来有证据的结论**；而且压掉之后它**不会在下一轮自动重现**。⛔ **例外是决策 ②（永久砍掉一块搜索面）与 ④（让上一轮数据不可比）** —— 代价不可逆，整轮不达标时并入 ⑤，**但必须把"它已过门槛"这句话写出来**。
- **P1 · 平台状态型（「已读不回」「简历未通过」）在四层回应分层里有归宿了。** ⛔ **不是第五层** —— 四层分的是"对方的话里有多少可判定信息"，而平台状态**里没有对方的话**，分类轴不同，所以它是**并排的旁栏**。⭐ **单列计数，⛔ 不计入 `本轮最小样本` 的「有回应」数**：那个门槛存在是为了保证"有足够的量能分出三档理由类型"，而平台状态在定义上分不出任何理由档 —— 拿它凑够门槛，只会得到「体检说够了、收敛环没米下锅」。✅ 它唯一的用途：**证明对方看到了**，也就是**唯一能证伪"无回应多半是没被看到"的材料**。**为什么这条是 P1 而不是 P2**：实测里执行者对它的临场归类**直接决定了样本达不达标**，框架把一个决定性分叉交给了临场判断。
- **P1 · 「该问没问 / 该追没追」有了自己的出口**（实测有 3 条这类信息无处可去）。原本只有登记簿一个落点，⛔ **而登记簿只通向「开分支」** —— 它进去就出不来（永远凑不出独立事件数，也写不出证伪判据）。现在：落在报告 §5.2「**下一轮的执行改进项**」，⛔ 不进 `discoveries.md`，并在 L2 兜底规则上开了这一个明确例外（它不是归不了类，是**有归宿**）。
- **P1 · 补「不能联网时退化成什么」**（`03-company-analysis` 有，本模块没有，执行者只能跨模块搬口径）。主链路**不依赖**联网；变的是四处：`公开可查` 整档不可用 / 报告顶部写一行 / **来源独立性核对退化成保守口径（判不出就合并计 1，因为把一个人的一次判断当市场形态的代价远高于漏判一次真扩散）** / 决策 ② 的旁证拿不到。
- **P1 · 周期复盘新增「回溯提示」**。实测里用户三个月前本该跑 offer 模块，两个机会现在已经过期，**框架没有任何机制指出这一点**。现在报告 §5.3 扫台账找「当时该做而没做」的动作。⭐ **目的不是让用户后悔** —— 过期的追不回来，说它只会让人难受；⛔ **措辞一律落在「下次这类事发生时提醒我」上**，产出是**下次的触发条件**，不是这次的检讨。
- 未动 `discoveries.md` / `branches.md` 契约（§9 / §10 最小字段不变）→ **patch**。
