# SKILL · 面试执行与当天复盘

> **把本文件整份交给你的 agent 即可。** 贴进对话、放进项目目录、当系统提示，都行。本文件是纯 markdown，不依赖任何特定 agent 产品的机制（不需要注册斜杠命令、不需要自动加载、不需要特定目录约定）——`SKILL.md` 只是一个文件名约定，不是某一家的格式。

## 0. 这个 skill 在干什么

**一条链，五步，顺序不可换：**

```
面试中（按一页纸执行，现场只记不判）
   ↓ 当天，最好在两小时内
当天三问（问了什么 / 哪里讲不通 / 关注点对不对得上）
   ↓
红旗绿旗回填 —— 三态：证实 / 证伪 / 未验证
   ＋ ⭐ 判据之外：对方主动给的、会改变公司判断的事实（回流疑点表，见 §4.5）
   ↓
⭐ 溢出登记（跑题跑出来的东西，零门槛）
   ↓
反哺：改事实池表述 / 调定位假设 / 喂发散信号
```

### ⭐ 先说清楚：这是一套协议，不是一个题库

**本文件里没有任何一道面试题，也没有"高频问题排行"。** 三张表发布时是空的，它们要装的是**你自己**的问题。

- 想让 agent 帮你猜这家公司会问什么 → **不做**，见 [`README.md` 不做什么](README.md)。
- 想要一份"标准答案"话术 → **不做**。「应该怎么答」那一列必须从你的事实池里长出来；抄来的答案在追问第二层就会塌，而追问恰恰是这里要记下来的东西。

### ⚠️ 全文最重要的一条纪律

**当天做。**

不是"这周找时间"，是**面试当天**，最好在离开那栋楼后的两小时内。

**犯了会怎样**：隔一夜，你脑子里剩下的是**结论**（"感觉还行""那个技术负责人挺厉害"），细节全没了——而这个模块的全部价值在细节里：对方问题的**原话**、你卡壳的是哪半句、他追问的第几层你接不住、他在你说到某件事时突然坐直了。结论对下游没有任何用处，细节才有。

⏱️ **时间不够就砍范围，不要延期。** 只有二十分钟，就按这个顺序砍：**第一优先 [§3](#3-面试后当天三件事) 的当天三件事 + [§4](#4-红旗绿旗回填三态) 的三态回填**（＝复盘卡 §1-§4），**第二优先 [§4.5](#45--判据之外对方主动给的事实往哪放) 的「对方说了什么值得记的」+ [§5](#5--溢出--意外收获登记) 溢出栏**（这两栏最容易忘——它们记的都是"我没预先问的东西"，而复盘的注意力天然全在"我预先写下的那几条"上），其余明天补。
⭐ **§4 不能被砍到第二天**：三态是唯一喂给下游做判据校准的东西，而它同样靠当天的记忆——隔一夜就只剩"感觉还行"，没法逐条回填。

## 1. 开跑前

### 1.1 你要给我什么

| 输入 | 必需？ | 缺了会退化成什么 |
|---|---|---|
| **一场刚面完的面试** | ✅ 必需 | 唯一真的缺不得的。没有它这个模块无事可做 |
| **你还记得的三五件事** | ✅ 必需（散着说就行） | 见 §1.2。你说得越碎越好，整理是我的活 |
| `assessments/<公司>.md`（面试前评估） | 可选，但**这是唯一会真正改变产出质量的一项** | 缺了红旗绿旗**没有对照基准**。⭐ **这一场照跑不误**（[§4.4](#44-没有上游评估时怎么办) 已把"到底跑不跑"写死了：跑），但我会让你手工列 3 个"当时想验证的点"顶上，在复盘卡里标注**"事后补的基准，可信度低"**，**不把这部分喂给下游做判据校准**，并把这 3 个点留成**下一场一页纸的第一稿** |
| 现场勾过的一页纸 | 可选 | 缺了只能靠回忆重建，问题原话大概率丢失。我会区分标注哪些是**原话**、哪些是**你转述的** |
| `positioning.md`（你预设的定位） | 可选 | 缺了 §3 第三问填不了。**我不猜**——明确告诉你"给我 2-3 条就能补完这一节" |
| `facts.md`（事实池） | 可选 | 缺了「已知高风险问题」只能从这一场被追问到的点反推，不是系统性扫出来的 |
| 之前几场的复盘卡 / 问题积累表 | 可选 | 缺了没法判断"同类问题是不是反复出现"，§7 的反哺建议会停在"本场观察"这一级，不上升为修订建议 |

### 1.2 ⭐ 最小可接受形态

**一场刚面完的面试 + 你还记得的三五件事。**

就这些。你可以这样说：

> *"刚面完，一个半小时，见了技术负责人和一个像是创始人的人。他们问我以前带过多少人，我答得挺乱。我问了他们客户是怎么用的，对方讲了个具体例子。后来聊到我以前折腾过的一个东西，那个技术负责人聊了半天，明显比聊岗位兴奋。哦对，中间他说了句他们排期是产品直接定的。"*

**这已经够了。** 我从这段话里能拆出：被问到的问题 1 条、答得不好的地方 1 条、红旗绿旗可回填线索 2 条、溢出 1 条、⭐ **「对方说了什么值得记的」1 条**（*"排期是产品直接定的"* —— 他主动给的，而且把它拿掉你对这家公司的判断会变；**如果你面试前正好有一条判据在问排期决策权，它就留在 §4 那一栏，不重复登记**）。剩下的我会**一次性**把还缺的列全问你。

⚠️ **但要把话说全：照最小形态给，你会拿到什么、拿不到什么。**

- **你会拿到**：一张填得起来的复盘卡（§3 的三问 + [§4.5](#45--判据之外对方主动给的事实往哪放)「对方说了什么值得记的」+ §5 溢出栏都能写满）、问题积累表几行、高风险问题清单若干条。**这本身就是完整产出，不是半成品。**
  ⭐ **注意 §4.5 这一栏在最小形态下照样能写满**：它登记的是**对方主动给的**事实，不需要你面试前写过任何判据——⛔ **别把它和 §4 三态一起归进"缺上游就填不了"那一档**。
- ⛔ **你拿不到**：**§4 那一节填不出能参与下游校准的三态。** 三态回填的对象是**面试前成对写下的 🔴/🟢 判据**——最小形态里没有它。事后补的基准按 §4.4 一律标 `事后补的基准，可信度低`，且**不喂给下游做判据校准**。
- **一句话**：**最小形态足够产出一份复盘卡，不足以产出任何一条能进下游的判据结论。** 想要后者，唯一的办法是面试**前**把那对判据写下来（上游模块见 §1.1；自己手写三条也算，**只要是事前写的**）。

⛔ **不要求你先按格式整理好再来。** 顺序乱、时间线跳、想到哪说到哪——都是正常输入，不是"格式不对"。

### 1.3 ⛔ 四条禁止（写给 agent 自己）

1. **不许报错退出。** 上游文件缺失是常态不是异常。缺什么就降级跑什么，并在复盘卡里明写少了哪一层。
2. **不许静默自己编。** 用户没说的细节就是没有。想不起来的问题原话，写"记不清原话，大意是……"并标 `你转述的`，**绝不替他补一个像模像样的原话**。红旗绿旗更是如此——没聊到就是 `未验证`，不许因为"听起来应该是这样"就填 `证实`。
3. **不许一次只问一个问题挤牙膏。** 要什么一次性列全（例：*"还缺三件事：① 对方有没有问到你上一段离开的原因 ② 你面试前写的红旗里有一条是关于排期决策权的，今天聊到了吗 ③ 有没有哪一段你俩明显聊嗨了"*）。用户一次回答完，就该开跑。
4. **不许把该自己解决的整理工作推给用户。** 他散着说 → 我整理成复盘卡；时间线跳 → 我排序；同一件事说了两遍 → 我合并；他说"那个我答得挺烂的"→ 我追问是哪一层没接住，而不是原样抄进表格。

### 1.4 阈值与来源等级

**这个模块里所有的数字都是参数，不是定论。** 每条都标了来源等级，标成后两档的**就是编的**，请按自己的情况改：

| 参数 | 默认值 | 来源等级 | 说明 |
|---|---|---|---|
| 复盘时限 | 面试当天，最晚 24 小时内 | `默认建议值` | 方法论里写的是"当天"，但没有做过"隔一天 vs 当天"的对照 |
| 一条问题升级进「已知高风险问题」 | **1 次**（简历强主张被追问且答不通，第一次就进） | `默认建议值` | 这类问题只要出现过一次，下次几乎一定还会被问——因为它是你**自己写在简历里招来的** |
| 同类问题触发"事实池表述要改" | **3 家不同公司** | `纯占位待校准` | ⚠️ 这个 3 是编的。样本量的判断没有任何实践依据支撑 |
| 同一家公司多轮问同一个问题 | 算 **1 次**，不算重复出现 | `默认建议值` | 同一家公司内部串过口径，不构成独立样本 |
| 溢出登记门槛 | **无门槛** | — | 刻意为零。见 §5 |
| ⭐ 「对方说了什么值得记的」登记门槛 | **无门槛** | — | 同样刻意为零。见 [§4.5](#45--判据之外对方主动给的事实往哪放)。⛔ 空栏要写「本场无」 |
| 面试表现评分 | **不存在这个参数** | — | 见 [`README.md` 不做什么](README.md) |
| ⭐ 红旗绿旗的**实际回填率** | 约两成（一次端到端实跑测试（角色扮演，不是真实面试）：9 条判据 → 2 证实 / 0 证伪 / 7 未验证） | `纯占位待校准`（⚠️ 一次端到端实跑测试（角色扮演，不是真实面试）的观察，样本只有 1 场，**不构成标定**） | ⚠️ 写在这里是为了给你一个预期：**`未验证` 占掉一大半是常态，不是你没做对**。它的实际含义是「**判据的排序比数量重要**」——见 §4.1。⭐ **真实面试里这个比例是多少，没有人测过** —— 这个数只用来说明「回填率天然不会高，跑出一堆未验证不是你做错了」 |

## 2. 面试中

> 这一节不是给 agent 执行的，是**面试前十分钟给人扫一眼**的。带进现场的是 [`03-company-analysis/interview-strategic-assessment`](../03-company-analysis/interview-strategic-assessment/) 产出的那张一页纸，不是本文件。

### 2.1 按上游产出的一页纸执行，不临场改题

问题的顺序、优先级、危险回答/好回答的判据，在面试前就定好了。**现场只做三件事：问、听、记。**

⚠️ **不要在现场重新设计问题。** 临场想出来的问题几乎一定是"这个氛围下顺嘴问的"，而不是"我事先判断过它能验证什么"——问了也不知道答案算好算坏。真临时冒出来的好问题，记进备用区，下一轮问。

### 2.2 ⛔ 不当场对材料口径矛盾表态

你在评估阶段发现的"这里跟那里对不上"，**当面用可回旋的措辞去求证，不用陈述句下判断**：

> ✅ *"我看到公开材料里写的是 A，刚才您提到的是 B，是我理解得不对吗？"*
> ❌ *"你们对外说的和实际不一样。"*

不影响决策的口径差异，**不主动戳穿**。

⚠️ **犯了会怎样**：这不是礼貌问题，是有效性问题。一旦对方进入防御状态，**这场面试后面的信息密度就归零了**——而你还有六七个问题没问。

### 2.3 观察类问题用行为化追问验证，不停留在标签化回答

组织文化、协作机制、决策权限这类问题，对方给出的第一层回答几乎一定是**标签**（"我们比较扁平""沟通很顺畅""技术驱动"）。**标签的信息量是零**——没有一家公司会说自己层级森严。

**追一句，把标签换成一件发生过的事**：

| 对方给的标签 | 你该追问的 |
|---|---|
| "我们比较扁平" | *"最近一次产品和研发对需求有分歧，最后是怎么定的、谁拍的板？"* |
| "技术驱动" | *"上一个大的技术方向调整是怎么发生的，是谁先提出来的？"* |
| "我们很重视质量" | *"上一次线上出问题，事后做了什么？"* |
| "客户反馈很好" | *"能讲一个具体客户吗——他们哪个部门、多久用一次？"* |

⭐ **判据：对方的回答里有没有一件可以被复述的具体的事？** 没有 = 你拿到的还是标签，这条在复盘时只能记 `未验证`（见 §4）。

### 2.4 现场记什么

只记三类，别的都不记（记多了会分心，且会让对方觉得你在做笔录）：

1. **对方问题的关键词**（回家扩成原话）
2. **你卡壳的位置**（打个星号就行）
3. **一页纸上红旗绿旗的勾**——⚠️ 三个框：☐证实 ☐证伪 ☐**未验证**。没问到、没聊到，勾"未验证"，**不要空着**（空着回家就分不清是没问还是忘了勾）

## 3. 面试后当天：三件事

> ⏰ 当天。见 §0。

### 3.1 记录被问到的问题 —— **原话优先**

**原话 > 转述 > 归纳。** 每条标出属于哪一档。

为什么较真到这个程度：*"你怎么保证数据质量"* 和 *"你们那套东西上线之后，出错了谁负责修"* 归纳出来都是"问了数据质量"，但**前者问的是方法，后者问的是责任归属**——你要准备的答案完全不同。**一压成归纳，这个区别就永久丢失了。**

每条问题落进 [`templates/问题积累表.md`](templates/问题积累表.md) 的一行：`日期 | 公司 | 问题 | 我的回答 | 应该怎么答`。

⚠️ 「我的回答」写**你当时实际说的**，不是你现在想到的更好的版本。那个版本写在「应该怎么答」列——**两列分开，就是这张表的全部意义**：它记录的是差距，不是答案。

### 3.2 讲不通 / 被追问的地方 —— **这一栏空着就等于没复盘**

这是全表最重要的一栏，也是最容易空着的一栏（因为写它不舒服）。

**"讲不通"有六种形态，都要记**：⭐ **前五种是"我这边出了什么问题"，第六种不是**——它是"对方给了东西，我没接住"。

| 形态 | 长什么样 | 它在说什么 |
|---|---|---|
| **接不住追问** | 第一层答得挺顺，追问到第二三层开始绕 | 你对这件事的理解只有一层深，或者这件事本来就不是你主导的 |
| **口径不一致** | 同一件事，跟这家说的和跟上一家说的不一样 | 事实池里这条的口径没有裁定过 |
| **数字/规模答不上来** | "大概……好像是……记不太清" | 简历里写了强主张，但支撑它的细节没准备 |
| **对方追问后你降调了** | "其实主要是团队一起做的" | ⭐ 这条最有诊断价值：**你自己都知道这个表述撑不住**，它就该改 |
| ⛔ **把待核实的东西当确定的说出去了** | 你在面试里，把 `facts.md`「待核实区」里**还没核实的数字或说法**，当成确定的讲了出去 | ⭐ **性质与前四种不同：这是硬约束被破，不是"没准备好"。** 待核实区的东西下游一律不许用，而它已经被你说给对方听了 |
| ⭐ **该追没追** | 对方主动说了一件**重要的事**（一个具体事件、一个人事变动、一句关于他们自己怎么运转的话），你"哦"了一声就过去了，没有追下去 | ⭐ **性质与前五种都不同：前五种是"我没准备好"，这一种是"我在现场没反应过来"。** 修法也不同 —— 见 [§3.2.2](#322--第六种形态该追没追它修的是现场习惯不是准备) |

⚠️ **agent 注意**：用户说"那段我答得挺烂的"时，**追问是哪一种形态**，不要原样记录。六种形态指向完全不同的修订动作。

⭐ **第六种不会被用户主动报告**，因为它不难受——当时那一刻是顺利的（对方在讲，你在听）。它只会以"他还提了一句……"的形式顺口出现在你的复述里。**agent 每场要主动扫一遍**：用户复述里凡是出现「他还说了 / 他顺口提到 / 中间他讲了一句」，都停下来问一句：*"这条你当时追了吗？追到了什么？"*

### 3.2.1 ⛔ 第五种形态要单独说：它的修法和前四种不一样

前四种的落点都是**改表述**（换个讲法、裁定一个口径、把答案准备好）。第五种不是：

- **修法是回去核实。** 核得出来 → 把它从「待核实区」挪进事实池正文，以后可以放心讲；核不出来 → **把这句话从材料里删掉**，⛔ 不是"换个说法继续讲"。
- **它还有第二重后果**：这句话**已经进了对方的记录**。下一轮或下一家如果你改了口径，它会立刻变成第二种形态（口径不一致）——所以核实这件事有时限，不能拖到下次面试之后。

⭐ **每场必查的固定检查项（不管用户有没有提，都要问一次）**：

> *"今天有没有说出 `facts.md` 待核实区里的内容？"*

**这一条不能靠用户主动想起来。** 说的时候他通常没意识到（那句话在他脑子里已经跟真的一样了），事后也不会把它归进"讲不通"——因为当时讲得很顺。
⛔ **用户答"没有"也要记一笔「已检查：无」。** 空着和"检查过，没有"是两件事：前者三天后没人分得清是查过还是忘了查。

### 3.2.2 ⭐ 第六种形态（该追没追）：它修的是现场习惯，不是准备

前五种形态，修法都落在**面试之间**：改一句表述、裁定一个口径、把答案准备好、回去核实。**第六种落在面试之内。**

- **它的修法是**：把这条写进下一场的现场提醒——**对方主动给出一件具体的事时，先追一句再往下走**（追什么见 [§2.3](#23-观察类问题用行为化追问验证不停留在标签化回答) 的行为化追问表）。⛔ 不要指望"下次我注意点"，写不进一页纸的提醒等于没改。
- ⛔ **它不进「已知高风险问题清单」。** 那张清单收的是"你写了什么招来的问题"（见 §6.2），而这一条跟你写了什么没关系。**记错地方 = 它下次不会出现在任何一张你会看的纸上。**
- ⭐ **它几乎总是成对出现**：只要你记了一条"该追没追"，那条**半截的信息本身**就一定要落进 [§4.5](#45--判据之外对方主动给的事实往哪放) 的「对方说了什么值得记的」。**一条记形态、一条记内容，缺哪一半都不完整**——只记形态，那件事本身就丢了；只记内容，下一场你还会在同一个地方错过。

⚠️ **犯了会怎样**：这是六种形态里**唯一一种代价落在对方身上而不是你身上**的——前五种丢的是"你答得不够好"，这一种丢的是**对方已经免费给你、而且不会再给第二次的信息**。同一场面试里对方通常只会主动松口一两次。

### 3.3 面试官关心的点 vs 你预设的定位 —— **对不上是最有价值的信号**

先分别写下来，再比对：

- **他今天花时间最多的是什么**（不是他嘴上说重要的，是**实际聊得最久的**）
- **他反复回来问的是什么**
- **你预设自己是来解决什么问题的**（来自 `positioning.md`）

三种结果：

| 比对结果 | 意味着什么 | 该做什么 |
|---|---|---|
| **对得上** | 定位假设在这一场被支持了 | 记一次正向样本，不改任何东西 |
| **对不上，且他关心的你答得还行** | ⭐ 你可能被市场看成另一种人——**这往往比"对得上"更有价值** | 进 §5 溢出登记，喂给方向优化 |
| **对不上，且他关心的你答不好** | 要么定位偏了，要么简历把你摆到了一个你撑不住的位置 | 进 §7 反哺，且是最高优先级的那一类 |

⚠️ **不要因为"最后聊得挺开心"就把对不上写成对得上。** 这一栏记的是**内容落差**，不是氛围。

## 4. 红旗绿旗回填：三态

### 4.1 三个态，一个都不能少

面试前你（或上游模块）为每条关键判断写过一对判据：🔴 什么样的回答算危险、🟢 什么样的回答算靠谱。面试后逐条回填：

| 态 | 什么时候标它 | 下游怎么用 |
|---|---|---|
| **证实** | 对方给出了**一件具体的事**，落在你事先写的 🔴 或 🟢 范围内。⭐ **判据事先枚举过的任何一种回应形态**（答不上来 / 一句具体的回避话术 / 某种特定说法）**被观测到，就是这一档的观测**——见 §4.3 补充判据 2 | 该判据得到一次真实检验，可参与校准 |
| **证伪** | 对方给出了**一件具体的事**，**与判据相反** | 该判据可能写错了，可参与校准 |
| ⭐ **未验证** | 没问到 · 没聊到 · 问了但对方回避 · 聊了但你听不懂/记不清 | ⛔ **不参与校准。** 它是"没测过"，不是"测过了不成立" |

⚠️ **先把预期说清楚：`未验证` 会占掉一大半，这是正常的。**

一次端到端实跑测试（角色扮演，不是真实面试；场景设定为只见到一位面试官、能提问的时间十几分钟）里，**9 条事先写好的判据，回填结果是 2 证实 / 0 证伪 / 7 未验证** —— 回填率约两成。
⭐ **这不是你做错了，是这套东西在紧约束下的产出率。** 一页纸上写 9 条、现场问得完 2-3 条，是常态。
（来源等级：`纯占位待校准` —— ⚠️ 这是**一次端到端实跑测试（角色扮演，不是真实面试）**的观察，样本只有 1 场，**不是标定过的比率**，你自己的比率大概率不同。）
⭐ **真实面试里这个比例是多少，没有人测过** —— 这个数不是实证结论，只用来说明一件事：**回填率天然不会高，跑出一堆 `未验证` 不是你做错了**。
**它对你的实际含义是**：⭐ **判据的排序比数量重要**——排前三的那几条决定了你这一轮真的能测到什么，后面的大概率只能留到下一轮。

### 4.1.1 ⭐ 每条都要写清它验证的是哪一条（疑点编号 / 必要条件编号）

复盘卡红旗绿旗表里有一列 **「验证哪条（疑点编号 / 必要条件编号）」**，⛔ **它不许空着**。

**从哪来**：照抄上游 `assessments/<公司>.md` §3 分层问题清单里「验证哪条疑点 / 哪条必要条件」那一列的编号（`Q<n>` / `必要条件<n>`）。⛔ 不要在复盘时重新发明一套编号——那样两份文件就对不上了。
**没有上游时**：写 `自定：<一句话>`，并注明它属于**「公司成不成」**还是**「我要不要去」**（这两类的下游处理不同）。

⭐ **它的用途只有一个，但很要紧：让下游知道一条"未验证"到底有多重。**

| 这条判据挂的是 | 一条 `未验证` 意味着 | 下游该怎么办 |
|---|---|---|
| **必要条件**（回答"我去不去"） | 你到现在还不知道自己去不去 | ⭐ 补测（下一轮放最前面 / 面试外的渠道问）**或显式写下"我接受这条没测出来就做决定"** |
| **疑点 / Kill Switch**（回答"公司成不成"） | 对公司的判断少了一块 | 按剩余证据的强度决定要不要追 |
| **次要疑点** | 少了一块无关紧要的 | 可以留到下一轮，也可以直接从下次的一页纸里删掉 |

⚠️ **缺了会怎样**：下游模块**只读这张复盘卡**。没有这一列，一条挂着必要条件的"未验证"和一条挂着次要疑点的"未验证"**在纸面上长得一模一样**——于是最要紧的那条会被当成普通待观察项排到后面。
⛔ **别指望"回头翻一下面试前评估就知道了"**：那需要**同时读两个文件**才能把链还原，而下游拿到的只有这一张卡。这也正是[契约 §6](../../docs/module-contracts.md) 把这一列写进最小字段的原因。

⭐ **顺带一个自查**：如果某条判据你**指不回任何编号、也写不出一句"自定"**，那它面试前就不该被写进一页纸——它没有在验证任何东西。下次删掉。

### 4.2 ⛔ "未验证"不等于"证伪"

**这是本模块最容易写错、后果也最重的一条。**

⚠️ **犯了会怎样**：把"没问到"记成"证伪"，会直接污染下游方向优化模块的判据校准——**它会以为某条判据被证明是错的，从而把它删掉或改写**，而其实那条判据从来没被测过。你会亲手删掉一条可能有用的判据，而且再也想不起来为什么。

同一个错还有一个更隐蔽的版本：**因为"感觉不太对"就标证伪**。

⛔ **标"证伪"必须有一条你能写下来的原话或具体事件。** 写不出来 → `未验证`。没有例外。

### 4.3 ⭐ 怎么区分"对方回避了"和"对方否认了"

**这是三态能不能落地的关键，也是最需要判据的地方。**

> **一句话判据：你能不能从对方的回答里，复述出一件具体的事？**

⚠️ **这条判据有一个例外分支，顺序不能反。**

> **先查一遍你面试前写下的 🔴 / 🟢 有没有枚举过这一种回应，再用上面那句一句话判据。**

因为判据**预先枚举过**的回应形态（答不上来 / 一句具体的回避话术 / 某种特定说法）被观测到时，**即便你复述不出任何一件具体的事，也判 `证实`**——见下方**补充判据 2**。
⛔ **两条判据在这里会给出相反的结果，例外分支优先。** 反过来用（先落 `未验证` 再想起来查判据）就是本模块代价最高的那个错：**一条真的被测出来的红旗被归成"没测过"，然后永久消失。**

| | 否认（→ 可标 `证伪`） | 回避（→ 必须标 `未验证`） |
|---|---|---|
| **形态** | 给出与判据相反的**具体事实或事件** | 换层级 / 换话题 / 把问题还给你 / 给一个对任何公司都成立的答案 / 明确说不方便讲 |
| **例（问"排期是谁定的"）** | *"排期是产品直接定的，工程这边评估工时，但优先级不参与投票。"*——这是一件具体的事，且与"工程有排期决策权"这条绿旗相反 → **证伪** | *"我们这边协作还挺顺的，大家都会一起讨论。"*——复述不出任何一件事 → **未验证** |
| **例（问"最大客户不续约怎么办"）** | *"去年确实丢过一个大客户，当时把交付团队拆成两组去补另外两家。"* → 有事件，可判 | *"这个我们内部有预案。"* / *"这个不太方便讲。"* → **未验证** |
| **检验方式** | 你能把它当**事实**转述给第三个人，且他会追问细节 | 你转述出来对方会说"所以呢？" |

⚠️ **右列的"必须标 `未验证`"有前提：这一种回应没有被你面试前的判据枚举过。** 枚举过的走例外分支（→ `证实`），见补充判据 2。

**三条补充判据**：

1. **明确说"不方便讲"= 未验证**，但**要单独记一笔**：什么问题会让对方关上门，本身是信息（进 §5 溢出栏，或进下一轮的必问项）。
   ⚠️ **同样受例外分支约束**：如果面试前的 🔴 里就写了「问到收费方式会说不方便讲 = 口径还没定下来」，那么他真这么说时，**判 `证实`**，不是未验证。
2. **对方愣住、绕开、把问题还给你，或用一句标准话术把问题挡回来** —— ⭐ **分两支，看你面试前那条判据里有没有预先枚举过这一种回应形态**：

   - ⭐ **判据里预先枚举过的任何一种回应形态被观测到 → 判 `证实`**（写在 🟢 那一侧就是证伪，方向按判据走）。**枚举过的形态不止「答不上来」一种**，至少包含这三类：

     | 被枚举的形态 | 面试前判据长什么样 | 现场观测到什么算命中 |
     |---|---|---|
     | **答不上来** | 🔴「连"上一次线上出问题之后做了什么"这个问题本身都答不上来 = 没有形成复盘动作」 | 他当场答不出、绕开、把问题还给你 |
     | ⭐ **一句具体的回避话术** | 🔴「用 *"我们不太依赖某一家模型"* 这类说法挡回来 = 在回避问题本身」——**上游模块把这类话术逐字写进 🔴 是常态，不是例外** | 他**说出了**那句（逐字，或同义到你能认出是同一句），且后面没有落到任何具体的事 |
     | **某种特定的说法** | 🔴「只会讲"各行各业都有客户"，说不出具体一类」 | 他给的正是那种说法 |

     **判断依据只有一条**：**你面试前写下的 🔴 或 🟢 里，有没有这一种回应？** 有 → **你事先设计的测试被触发了**，这是判据自己枚举过的结果，**不是"没测过"**。
     此时那条写得下来的事件就是：「我问了这个问题，他用了我事先写在 🔴 里的那一句 / 那一种回应，然后没有落到任何具体的事。」
     ⛔ **事后追加的形态不算。** 必须是面试**前**就写在一页纸上的那一档——事后想起来"这句话我早就觉得可疑"是**事后合理化**，按 §4.4 处理（标 `事后补的基准，可信度低`，**不喂给下游做判据校准**）。

   - **判据里没枚举过这一种回应** → **未验证**，并单独记一笔。⚠️ **"是信号"不等于"是证伪"**：对方给了一句谁都会说的套话，证明的是"这个问题让他不舒服"，**不是"你那条判据成立"**——你那条判据问的是别的事（他能不能讲出一次具体复盘），而它这一场根本没被测到。

   ⛔ **两支不许混用。** 把第一支记成`未验证`，会让一条**真的被测出来了**的红旗白白作废——⭐ **这是本模块代价最高的一个错**：它既不参与下游校准，也不会进下一轮的优先项，**这条信号就永久消失了，而且你不会知道它消失过**（表面上只是多了一格"未验证"）。把第二支记成`证实`，就是 §4.2 那个错。

   ⚠️ **agent 的动作顺序**：遇到"对方绕开了 / 给了句套话"，**先回头把这条的 🔴 和 🟢 逐字读一遍**，再判态。⛔ 不许跳过这一步直接按"复述不出具体的事"落 `未验证`——§4.3 开头那句一句话判据管的是**判据没枚举过**的那一支，本判据是它的例外分支。
3. **你没问 = 未验证**，且**要写清楚为什么没问**（时间不够 / 忘了 / 气氛不合适 / 前面的回答让这条不重要了）。最后一种要单独标——它意味着这条判据可以从下次的一页纸里删掉，是真正的收敛。

### 4.4 没有上游评估时怎么办

⭐ **先把"那到底还跑不跑"这个问题显式回答掉：跑。但产物降级，而且用途换一个。**

这一节此前留了一个自相矛盾的口子：一边让你事后手工列 3 个"当时想验证的点"顶上，一边又说**这样列出来的点会被你已经听到的答案带偏**。**两句都对，但没有一句回答"那还跑不跑"** —— 于是执行者只能自己猜。现在写死：**跑**，理由两条：

1. ⭐ **这 3 个点的真正用途不是检验这一场，是给下一场攒判据。** 你写不出这 3 个点，说明面试前也确实没想清楚要验证什么——不写下来，下一场还是一样。
2. 复盘卡其余各栏（问题 / 讲不通 / 关注点落差 / 溢出 / 对方说了什么值得记的）**根本不依赖上游判据**，照跑不误。为了红旗绿旗那一栏不完整就整场不做，是把能拿到的也一起扔了。

⛔ **但它只降级不升级**：

⚠️ **必须在复盘卡里标注「事后补的基准，可信度低」，并且不喂给下游做判据校准。**

理由：事后回忆出来的"我当时想验证的"，会不自觉地被你**已经听到的答案**带偏——这等于用结果去写考题，然后宣布自己全答对了。它可以帮你整理这场面试，但不能当成对判据的检验。

⭐ **一条可执行的减偏动作，顺序不能反**：

> **先写"我当时担心什么"，写完停笔；再写"结果是什么"。两段分开写。**

⛔ **顺序颠倒（先摆出对方今天说了什么，再回头写"我当时就是想验证这个"）就是事后合理化。** 那 3 个点会一条不落地全部"命中"——而**一条永远不会落空的判据，和一条根本没有的判据，是同一回事**（这正是本仓库反复讲的那条命题）。
⭐ **agent 的动作顺序**：先只问一句 *"今天进这场之前，你最担心这家哪一点？"* ——⛔ **在用户答完这一问之前，不要复述、不要总结、不要追问任何对方今天说过的话。** 这一步的全部价值就在"还没被答案污染"上；污染过就补不回来了，只能等下一场。

⭐ **「验证哪条」那一列仍然要填**，写成 `自定：<一句话>`，并注明它属于「公司成不成」还是「我要不要去」——⛔ 没有上游不等于这一列可以空着（见 §4.1.1）。

⭐ **这 3 个点写完不要扔**：它们是**下一场面试前那张一页纸的第一稿**。这是本节唯一能产生复利的产物——事后补的基准检验不了这一场，但它能让下一场的判据变成"事前写下的"。

### 4.5 ⭐ 判据之外：对方主动给的事实往哪放

一场面试里信息量最大的那几句，**常常不落在你事先写的任何一条判据上**——是对方自己松口讲出来的。

⭐ **它必须有一个明确的落点，因为现有的两栏都会（正确地）把它挡出去**：

| 你可能想放的地方 | 为什么放不进去 |
|---|---|
| [§4](#4-红旗绿旗回填三态) 三态回填 | 它不对应任何一条**面试前**写下的判据。硬塞进去就得事后补一条判据，而事后补的按 [§4.4](#44-没有上游评估时怎么办) 一律降级、不喂校准 |
| [§5](#5--溢出--意外收获登记) 溢出栏 | 溢出栏的唯一判据是"拿掉它，对**这家公司**的评估结论会不会变"。**会变 → 它不是溢出。** 这条判据没写错，问题是**挡出来之后以前没有任何一栏接住它** |

**所以复盘卡里单开一栏：「对方说了什么值得记的」**（模板 §4b）。

**登记什么**：对方主动透露的、**会改变你对这家公司判断**的具体事实。判据就是溢出栏那条判据**反过来用**：

> **把这句话拿掉，你对这家公司的评估结论会变吗？会变 → 进这一栏。**

**例**（这几条都不对应事先写下的判据）：某条业务线的负责人今年换过 · 上一个大客户当初是怎么谈下来的 · 某个模块其实是外部团队做的 · 他们内部谁能拍板买工具。

⛔ **它的去向和溢出栏完全不同，别搞混**：

| | 「对方说了什么值得记的」 | [§5](#5--溢出--意外收获登记) 溢出 |
|---|---|---|
| 它改变的是 | ⭐ **你对这家公司的判断** | ⭐ **你对自己的判断**（市场怎么看你） |
| 回流到哪 | ⭐ **面试前评估的疑点表**（`assessments/<公司>.md`）——更新那家公司的疑点，下一轮的一页纸从更新后的疑点表长出来 | 方向优化模块的**发散**那一侧 |
| 门槛 | 无，零门槛登记 | 无，零门槛登记 |

⭐ **回流疑点表时逐条注明它落在哪一条疑点上**（`Q<n>` / `必要条件<n>`）；落不上任何一条就写 `新疑点：<一句话>`。⛔ **「新疑点」这一档不许省**——对方主动讲的东西之所以值钱，恰恰因为它常常在你事先想到的那几条之外。

⚠️ **这一栏空着要写「本场无」，不要留白**（同 [§3.2.1](#321--第五种形态要单独说它的修法和前四种不一样) 那个固定检查项的道理）：留白分不出"对方今天什么都没主动讲"和"讲了但我没记"。

⭐ **它与 [§3.2](#32-讲不通--被追问的地方--这一栏空着就等于没复盘) 第六种形态成对出现**：追了 → 这一栏写完整的那件事；没追住 → 这一栏写**半截的那条**（写清缺的是哪一半），同时 §3.2 记一笔「该追没追」。⛔ **半截的也要写**：半截的事实就是下一轮开场的第一个问题，扔掉它等于把这条线索一起扔了。

## 5. ⭐ 溢出 / 意外收获登记

### 5.1 登记什么

**本场对话里跑题跑出来的东西**，三类：

1. **你讲得比对方还兴奋的话题** —— 你自己没意识到的兴趣或优势区往往在这里。**典型是与本岗位无关的话题**，但 ⚠️ **"与本岗位无关"只是典型例子，不是必要条件**——判它算不算溢出，以 §5.4 那条判据为准
2. **对方无意透露的行业信息** —— 他们在观察谁、什么东西在这个行业里正在变、哪类人不好招
3. **可复用的联系人或线索** —— 提到的某个工具、某个圈子、某个"你应该去跟 X 聊聊"

⭐ **三类都进这一栏、都零门槛登记、都要上报下游，且下游归同一个信号编号。**

⛔ **不许只报第 1 类。** 第 2 类（行业信息）与第 3 类（线索）恰恰是下游那条"这一轮产出的可能根本不是一个岗位"的决策的原料——**漏报它们，那条决策就永远没有输入**，而它是这整条发散线最远的那个出口。

### 5.2 为什么这一栏不能省

**这是本仓库里"投着投着发现新可能性"那条线的唯一数据采集点。**

主链路上所有其他表记的都是"我这次做得准不准"（收敛）。只有这一栏记的是"我原本不知道要找什么"（发散）。**没有这一栏，下游的发散分析就没有输入**——它不是"少一个字段"，是那条线**整个不存在**。

它的实现成本是**一段模板文字**。⛔ **任何一轮精简都不许删它。**

### 5.3 登记规则：零门槛

> **想到就写，不判断有没有用。判断是下游的事。**

⛔ **不要在登记这一步做筛选。** 别的地方都靠"重复出现 + 样本门槛"防止被一两次偶然带偏，但发散信号**天然是单次的、看起来像噪声的**——同一套门槛会把它当噪声全滤掉。

所以：**登记免费、不设次数门槛、不要求你说清楚它有什么用。** 门槛只加在后面"要不要真的按这个方向做点什么"那一步，不加在这里。

### 5.4 ⛔ 什么不算溢出

| 不算 | 为什么 | 该记去哪 |
|---|---|---|
| 与本岗位相关、**且支撑了你对这家公司的判断**的深入讨论 | 那是**正常面试内容**，不是溢出。⚠️ 注意是两个条件，不是只看"与岗位相关" | §3.1 问题积累表 / §4 判据回填 |
| 你答得好的那些问题 | 同上 | §3 |
| 对方夸了你几句 | 氛围不是信息 | 不记 |
| 面试官个人的履历/背景 | ⛔ 越界，见 [`README.md`](README.md) | 不记 |
| ⭐ 对方主动透露的、**会改变你对这家公司判断**的具体事实 | 按下面那条唯一判据：**结论会变 → 它不是溢出** | ⭐ [§4.5](#45--判据之外对方主动给的事实往哪放)「对方说了什么值得记的」，回流疑点表。⛔ **不是"不记"** |

⭐ **区分判据（唯一判据，以它为准）**：把这段对话拿掉，**这场面试对这家公司的评估结论会变吗？**
**不会变 = 它是溢出**（正是因为它在岗位判断之外，才有单独登记的价值）；**会变 = 它是正常面试内容**。

⚠️ **两条判据打架时，以这一条为准，不以「与本岗位无关」为准。**

⭐ **真正的发散信号往往就长在"与岗位相关"的边界上。** 一段与岗位相关、却暴露了**市场怎么看你**的对话——它改变的是你对**自己**的判断，不是对**这家公司**的评估结论，所以它是溢出。如果被"必须与岗位无关"挡掉，**本场信息量最大、最可能改方向的那一段就丢了**。

**最典型的一例就在 §3.3**：比对结果落在中间那一档（对不上，且他关心的你答得还行）。它当然与岗位相关——但把它拿掉，你对这家公司的判断一点不变，变的是"你被看成哪一类人"。⭐ **§3.3 那一档明确要求进 §5，就是这条口径的直接后果。**

⛔ **判它的唯一问题是"拿掉它，对公司的结论会不会变"，不是"它像不像岗位话题"。**

⭐ **被这条判据挡出去的，去 [§4.5](#45--判据之外对方主动给的事实往哪放) 那一栏，不要丢掉。**
「会变 → 不算溢出」只说明**它不是发散信号**，⛔ **不说明它不重要**——恰恰相反：它改变的是你对**这家公司**的判断，落点是「对方说了什么值得记的」，回流的是**面试前评估的疑点表**。
⚠️ **判完就丢是这条判据最常见的用错方式**：判据本身没错，错在它以前**只有出口没有去处**——挡出去的那一条（常常是全场信息量最大的一句）就此消失，而表面上你只是"正确地没把它记成溢出"。

## 6. 三张表怎么用

| 表 | 粒度 | 什么时候写 |
|---|---|---|
| [`templates/当天复盘卡.md`](templates/当天复盘卡.md) | **一场一张** → `interviews/<公司>-<日期>.md` | 面试当天 |
| [`templates/问题积累表.md`](templates/问题积累表.md) | **一直累积一张** | 每场结束后追加几行 |
| [`templates/已知高风险问题清单.md`](templates/已知高风险问题清单.md) | **一直累积一张** | 改简历时 + 每场面试后 |

### 6.1 「已知高风险问题」怎么长出来

**两个来源，缺一不可：**

**① 事前扫（主要来源）**——从 `facts.md` 事实池里挑出**所有"看起来很强"的表述**，每条问自己一句：

> **如果对方追问细节，我答得上来吗？**

答不上来 → 立刻进清单，**并且现在就把答案准备好**。

⭐ **底层逻辑：写进简历的任何强主张，都等于主动出题。** 你写"主导了 X"，就是在邀请对方问"具体你做了哪部分、谁做的决定、结果怎么衡量的"。**没准备好的强主张不是加分项，是定时炸弹。**

**② 事后补**——§3.2 里"接不住追问"和"被追问后你降调了"那两类，**每一条都直接进清单**（阈值 1 次，见 §1.4）。

### 6.2 ⛔ 什么不进这张清单

**一次性事实型问题不进。** "哪年入职的""上一家公司多少人""什么时候能到岗"——这类问题答错只是记错了，不是风险，进了只会把清单撑成流水账，让真正的高风险项被淹掉。

⭐ **判据：这个问题会不会因为你**写了什么**而被问？** 会 → 进清单（是你自己招来的）；不会（任何候选人都会被问） → 不进。

## 7. 反哺规则

### 7.1 三条线，分开走

| 信号 | 触发条件 | 反哺到哪 |
|---|---|---|
| **同类问题反复出现且答得不好** | 在 **3 家不同公司**出现（`纯占位待校准`，见 §1.4）；同一家多轮问同一个问题**算 1 次** | 事实池里对应部分的**表述要改**，或**定位假设本身要调** |
| ⭐ **溢出登记** | **无门槛**，登记即上报 | 方向优化模块的发散那一侧 |
| ⭐ **「对方说了什么值得记的」**（[§4.5](#45--判据之外对方主动给的事实往哪放)） | **无门槛**，登记即回流 | ⭐ **面试前评估的疑点表**（`assessments/<公司>.md`）——⛔ 不是发散侧 |

⚠️ **样本不够就明说"证据不足，继续观察"，不要改。** 一两场面试答不好某个问题，最可能的原因是那两次没准备好，不是你的定位错了。**默认出口是"什么都不改"。**

### 7.2 ⭐ 这不是"改简历"

> **这是把面试当成对整个定位假设的一次真实市场检验。**

同一个现象，三种深度完全不同的解读：

| 现象 | 浅层解读（通常是错的） | 该考虑的解读 |
|---|---|---|
| "带过多少人"这个问题反复答不好 | 简历里管理经验那段要重写 | 你在投一类**默认要求带团队**的岗位，而你的实际经历不是这个形状——是**投的方向**不对，不是那段字不对 |
| 面试官反复问的都是执行细节 | 我该多准备些细节 | 你被看成执行层而不是你预设的那一层——**定位与市场认知有落差** |
| 每家都问"为什么想从 A 转到 B" | 准备一个更好的转型故事 | 这个转型在市场眼里**需要解释**，本身就是成本；要么接受它并把解释做扎实，要么重新考虑参照系 |

**所以反哺的落点顺序是**：① 表述（最便宜）→ ② 高风险问题清单（也便宜）→ ③ 定位假设（最贵，需要最多样本）。⛔ **不要跳过前两级直接动定位。**

### 7.3 交给下游

- **红旗绿旗三态**（⚠️ 只有 `证实` / `证伪` 参与校准，`未验证` 不参与）→ 方向优化模块的判据校准。⭐ **每条要带上它验证的疑点编号 / 必要条件编号**（见 §4.1.1）——⛔ 不带这个指针，下游分不出一条"未验证"是挂着必要条件还是挂着次要疑点
- ⭐ **标 `未验证` 的那些**：下游一律按**"未测得"**处理，⛔ **不会被当成"没问题"通过**（[契约 §6](../../docs/module-contracts.md) 的口径）。所以挂着必要条件的"未验证"要么补测，要么你显式写下"我接受这条没测出来就做决定"
- **溢出登记** → 方向优化模块的发散那一侧。⭐ **三类全部上报**（你讲得比对方兴奋的话题 / 对方无意透露的行业信息 / 可复用的线索），下游归**同一个信号编号**；⛔ 不要只报第 1 类
- ⭐ **「对方说了什么值得记的」** → **回流面试前评估的疑点表**（`assessments/<公司>.md`），⛔ **不是**方向优化的发散侧——它改变的是你对**这家公司**的判断，不是对你自己的判断。逐条注明落在哪一条疑点上（`Q<n>` / `必要条件<n>`），落不上就写 `新疑点：<一句话>`。
  ⚠️ **这一条的"下游"就在你自己手上**：疑点表不更新，下一轮的一页纸就还是照着旧疑点问——**对方免费给你的那件事，等于没给。**
- **"面试官关注点 vs 预设定位"的落差** + **答得不好的地方** → [`05-offer`](../05-offer/) 的"发展空间"那一维
- 每场面试都要在 `ledger.md` 台账里登记一行（含**对方回应原话**，见 [`docs/module-contracts.md` §8](../../docs/module-contracts.md)）

> ⚠️ 方向优化模块**就在本仓库里**（[`modules/06-positioning/`](../06-positioning/)，见仓库根 `CHANGELOG.md` 的模块表）。**你有没有在跑它，都不影响本模块使用**——复盘卡本身就是完整产出，三态与溢出栏留在那里，等它来读。

## 8. 来源标注

**复盘卡里每一条都必须带一个标注**，三选一：

| 标注 | 含义 | 附加义务 |
|---|---|---|
| `你给的` | 用户说的、他记下的原话、他现场勾的实测栏 | ⭐ 问题原话要再分一档：`原话` / `你转述的`——两者对下游的价值差很多 |
| `公开可查` | 官网、产品文档、公开报道、招聘页 | **必须附来源**。说不出来源的，降级成 `我推测的` |
| `我推测的` | 由现场信息推导、类比、经验判断得出（例：*"他反复问交付细节，我推测这个岗位实际偏实施"*） | ⭐ **必须附一句"要证实它，你该问谁 / 查什么"** |

### 为什么推测项必须附证实路径

因为**这就是下一轮面试的问题清单来源**。

`我推测的` + "要证实它你该问 X" = 一条候选问题，直接进下一轮的一页纸。

⚠️ **犯了会怎样**：不标来源，你会分不清"对方真的说过这句"和"我当时的感觉"。三天后你只会记得结论，然后**基于一个自己的推测去做去留决定**。

## 9. 不对劲的时候

| 症状 | 最可能的原因 | 你下一句该说什么 |
|---|---|---|
| ⭐ **「验证哪条」那一列全空着** | 直接从判据抄到了实测栏，跳过了往回指的那一格 | *"逐条补上它验证的是哪条疑点或哪条必要条件——有上游就照抄 `Q<n>` / `必要条件<n>`，没有就写 `自定：<一句话>`。不然下游分不出哪条"未验证"是要紧的。"* |
| ⭐ **红旗绿旗全都标成"证伪"** | 把"没问到 / 没聊到 / 对方绕开了"当成了"被推翻"——三态被压成了两态 | *"这几条你当时真的问了吗？没问到的改标未验证。问了的，把对方的原话给我——说不出原话的也改未验证。"* |
| **"讲不通/被追问的地方"那一栏是空的** | 要么真的一场都很顺（罕见），要么在回避写它（常见） | *"那把顺序倒过来问：今天有没有哪一刻你在心里想'糟了'？哪怕只有半秒。"* |
| **复盘卡写得像一篇面试感想**（"整体感觉不错，面试官很专业"） | 记的是氛围和结论，不是事实与落差 | *"把形容词全删掉，只留下：他问了什么（原话）、你答了什么、哪里卡住。感觉那部分我们最后再谈。"* |
| **溢出栏空着，但你刚才说了'后来聊嗨了'** | 溢出栏被当成"要有用才写"的栏，做了自我筛选 | *"聊嗨的那段是什么？不用管它有没有用——登记这一步不做判断。"* |
| ⭐ **用户复述里出现"他还提了一句 / 他顺口说……"，而复盘卡里没有这句** | 第六种形态（该追没追）没被记，那条半截的事实也没落进 §4.5 | *"他顺口提的那句，你当时追了吗？追到什么程度？——不管追没追，那件事本身都要落进「对方说了什么值得记的」；没追住就写半截的那条，并在「讲不通」里记一笔「该追没追」。"* |
| ⭐ **「对方说了什么值得记的」整栏留白** | 要么被当成"要重要才写"的栏做了自我筛选，要么被溢出栏的判据挡出来之后没人接 | *"今天对方有没有主动讲过关于他们自己的具体事？一件都没有也要写「本场无」。如果有、但你觉得'这不算溢出'——对，它本来就不进溢出栏，它进这一栏。"* |
| ⭐ **没有上游评估，而我（agent）已经先复述了对方今天说的话** | 违反 §4.4 的动作顺序，事后基准已经被答案污染 | *"这一场的"当时想验证的点"我不再让你补了——补出来也只会全部命中。改成：现在就写下你对**下一家**最担心什么，作为下一场一页纸的第一稿。"* |
| **产出里出现了一个面试表现分数** | 违反 [`README.md` 不做什么](README.md) | *"把分数删掉。改成：哪几条答得稳、哪一条完全没接住——它们的性质不同，别用一个平均值抹平。"* |
| **一场面试就得出"我的定位错了"** | 跳过了样本门槛，直接动最贵的那一级 | *"先看表述和高风险问题这两级能不能解释。定位要动，我需要看到同类问题在几家不同公司都出现过。"* |
| **问题积累表里「我的回答」和「应该怎么答」写的是同一句** | 把"应该怎么答"写成了自我辩护 | *"「我的回答」写你当时真的说出口的那句，不是现在想到的版本。这张表记的是差距。"* |

## 10. 三级自救阶梯（写给 agent）

⛔ **不许一出问题就让人接管。** 顺序是先自救两级，第三级才回报人。

| 级 | 什么时候到这一级 | 该做什么 | ⛔ 不该做什么 |
|---|---|---|---|
| **L1 有现成的，直接走** | 本文件里有明确规则命中（三态判据、溢出判据、高风险问题判据、反哺阈值） | 按规则执行，**不问**。例：用户说"那条我没问到"→ 直接标 `未验证`，不需要确认 | 不为"确认一下"打断用户。已有规则能裁决的判断，自己裁决 |
| **L2 没现成的，自己走通 + ⭐ 沉淀** | 用户说得散 / 时间线跳 / 面试形态特殊（笔试、群面、多轮连着面）/ 上游文件缺 / 出现本文件没覆盖的情况 | 用语义理解自己走通：散着说 → 自己整理成复盘卡；多轮连着面 → 拆成多条记录但共用一张溢出栏；缺上游 → 按 §4.4 降级并标注。⭐ **走通之后把学到的写回去**：新判据写进复盘卡的"本次新增判据"一节，下次直接回 L1 | ⛔ **不把"这次绕过去了"只留在会话里。** 没沉淀 = 下次还得再试一遍 = 等于没走通 |
| **L3 实在不行，才回报人** | L2 也走不通 / 触及 ⛔ 边界 / **只有用户本人才有的事实**（他预设的定位、对方到底说了什么、他为什么觉得那段答砸了） | 输出 **症状 + 已经试过什么 + 建议你做什么（给可选项）** | ⛔ 不输出裸错误 · ⛔ 不说"请提供更多信息"这种没有指向的话 · ⛔ 不把 L2 该自己解决的整理工作推给用户 |

**L3 的标准形态**：

> *症状*：红旗绿旗有 4 条我填不了——你说"没细聊"，但我分不出是没问到，还是问了对方绕开了。这两种的下游处理不一样。
> *已经试过*：从你给的对话片段里找过对应线索，只找到其中 1 条；按 §4.3 的判据试着分了一遍，剩下 3 条落不进任何一档。
> *建议你做*：三选一 —— ① 逐条告诉我"问了/没问"（最快，一分钟）② 把这三条当时对方回应的大意说一下，我按判据分 ③ 或者全标 `未验证` 收尾——**代价是这三条判据这一场等于没测**，下次要留在一页纸最前面。

## 11. 输出去哪

产出一份 `interviews/<公司>-<日期>.md`，模板见 [`templates/当天复盘卡.md`](templates/当天复盘卡.md)，字段以 [`docs/module-contracts.md` §6](../../docs/module-contracts.md) 为准：

**被问到的问题（原话优先）· 答得不好 / 被追问的地方 · 面试官关注点 vs 你预设的定位 · 红旗绿旗实测（证实 / 证伪 / 未验证）· ⭐ 溢出 / 意外收获**

⭐ 红旗绿旗那一节的每一条还要带上**它验证的疑点编号 / 必要条件编号**（见 §4.1.1）——这是 [契约 §6](../../docs/module-contracts.md) 的最小字段之一。

⭐ **另加一栏「对方说了什么值得记的」**（模板 §4b，见 [§4.5](#45--判据之外对方主动给的事实往哪放)）：对方主动透露、会改变你对这家公司判断的事实，回流**面试前评估的疑点表**。空着写「本场无」。
> ⚠️ 这一栏是本模块新增的，**尚未写进 [契约 §6](../../docs/module-contracts.md) 的最小字段** —— 下游模块目前不会主动来读它，**它的读者是下一轮的你自己**（通过疑点表）。下次动契约时应当把它补进去。

另外追加：问题积累表几行 + 高风险问题清单若干条 + `ledger.md` 台账一行。

完整走通一遍的样例：[`../../examples/sample-interview-debrief.md`](../../examples/sample-interview-debrief.md)。

⚠️ **如果你不打算用任何下游模块，也不影响**：这张复盘卡本身就是完整产出。三态和溢出栏留在那里不会浪费——它们是给未来的你看的。
