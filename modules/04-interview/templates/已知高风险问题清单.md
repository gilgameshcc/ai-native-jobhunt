# 已知高风险问题清单

> **一句话：写进简历的任何强主张，都等于主动出题。**
>
> 你写"主导了 X"，就是在邀请对方问"具体你做了哪部分、谁做的决定、结果怎么衡量的"。**没准备好的强主张不是加分项，是定时炸弹。**
>
> **粒度**：一直累积一张。改简历时扫一遍，每场面试后补一遍。填法见 [`../SKILL.md` §6.1](../SKILL.md)。

## 怎么填：从事实池里挑，一条一条问自己

**主要来源是事前扫，不是事后补。**

1. 打开 `facts.md` 事实池，把**所有"看起来很强"的表述**挑出来——主导、从 0 到 1、显著提升、负责、推动、优化了 N 倍、跨部门协调……
2. 每条问自己一句：

   > **如果对方追问细节，我答得上来吗？**

3. 答不上来 → 进下面这张表，**并且现在就把答案准备好**（不是"记下来以后再说"）。
4. 每场面试后补一轮：[`../SKILL.md` §3.2](../SKILL.md) 里"接不住追问"和"被追问后你降调了"那两类，**每一条直接进表**（阈值 1 次）。
5. ⭐ **第五种形态也进表**：本场**说出了 `facts.md` 待核实区内容**的那一句。它比前两类更急——**这句话已经进了对方的记录**，下一轮口径一变就是"口径不一致"。状态栏勾 `待补事实`，并写清核实截止时间；核不出来就走"改表述"那条出路（⛔ 这里的"改表述"是**删掉**，不是换个说法继续讲）。

## ⛔ 什么不进这张表

⛔ ⭐ **第六种形态「该追没追」不进这张表。** 它是"对方给了一件具体的事、我当场没追下去"——**跟你写了什么没关系**，所以它不满足下面那条判据。它的落点是**下一场一页纸上的现场提醒**（*"对方主动给出一件具体的事 → 先追一句再往下走"*），那条半截的信息本身落在复盘卡 §4b。
⚠️ **记错地方的后果**：它会躺在一张"改简历时才会打开"的表里，而它只在**现场**有用——于是下次照样错过。

**一次性事实型问题不进。** "哪年入职的""上一家多少人""什么时候能到岗"——答错只是记错了，不是风险。进了只会把表撑成流水账，让真正的高风险项被淹掉。

⭐ **判据：这个问题会不会因为你自己写了什么而被问？**

- 会 → 进表（**是你自己招来的**）
- 不会（任何候选人都会被问） → 不进

## ⚠️ 「答不上来，考虑改表述」这一档要认真对待

一条你自己都撑不住的强主张，有两条出路，**没有第三条**：

1. **补事实**——把细节找回来、把口径裁定下来，升级成"已准备"
2. **改表述**——把它降到你撑得住的程度（"主导" → "负责其中的 X 部分"）

⛔ **不许留在"答不上来"这一档带着它去面试。** 它一定会被问到——因为**是你自己写上去招人问的**。
