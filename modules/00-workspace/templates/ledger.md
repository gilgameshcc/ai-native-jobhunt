## 每个字段为什么要它

| 字段 | 为什么要它 | 不填会怎样 |
|---|---|---|
| **日期** | 漏斗分析的时间轴；也是"这条卡了多久"的唯一依据 | 分不出"没回音"和"还没到该回音的时候"——这两者对应的动作完全相反 |
| **公司** | 去重键。**全工作区统一一个短名** | 同一家写两种写法 = 统计里的两家公司。**它不会报错，只会静静地把漏斗算错** |
| **岗位** | 同一家公司的不同岗位是不同的信号 | 你会以为"这家没理我"，其实是"这家的这个岗没理我" |
| **级别**（S/A/B 之类） | ⭐ 让你能分层看回复率。**如果 S 级和 B 级的回复率没差别，说明你的定级规则没有区分力**——这是定级规则唯一的自检方式。**只写一个字母**：理由与待确认项属于定级结果文件，一个字母装不下 | 定级永远无法被验证，你会一直用一套没人检验过的标准 |
| **渠道** | 「不同渠道的回复率差异通常大于你对材料做的任何优化」——`默认建议值`，**一条未被验证的经验断言**（见下方警告） | 会把渠道问题误判成材料问题，然后反复改材料 |
| **用的哪一版** | 版本和结果之间的关联，是"要不要改简历"的唯一证据 | 改了简历之后无法判断有没有变好 |
| **状态** | 当前在漏斗的哪一层 | 无法统计各层转化 |
| **下一步** | ⭐ 带日期。没有下一步的条目会永远悬着 | 会积累一堆"投了但不知道现在该干嘛"的条目，最后你会整个放弃维护台账 |
| ⭐ **对方回应原话** | 见下方警告 | 见下方警告 |
| ⭐ **反向吸引** | 见下方警告 | 见下方警告 |

### ⚠️ 「渠道 / 用的哪一版 / 级别」这三栏**事后补不回来**

其余字段（公司 / 岗位 / 日期 / 对方原话）事后大多还能从聊天记录、邮件里翻出来。**这三栏翻不出来**——一个月后你不会记得某一条是从哪个入口发出去的、用的哪一版材料、当时判的是几级。

**只填四栏「公司 / 岗位 / 日期 / 对方回了什么」，你会拿到漏斗的形状；拿不到这三类结论**：

| 缺的栏 | 因此永久不可判的问题 |
|---|---|
| 渠道 | 「哪个入口有用」——「渠道差异通常大于材料优化」这条断言是 `默认建议值`（见下方警告），**而它决定了你该先看哪一边** |
| 用的哪一版 | 「要不要改表述」——改完有没有变好，只能靠版本与结果的对应关系 |
| 级别 | 「我的定级规则准不准」——高低级别的回复率没差别 = 定级没有区分力。这是定级规则唯一的自检方式 |

它们不是"数据量还不够"，是**字段就没记**，而且时间一过就永久缺失。**所以值得一开始就记**：三栏加起来一行不到十个字。

⛔ **不许因为这次填不上就把这三栏从表里删掉。** 留着空栏，它会提醒你去填；删掉之后没有任何东西会提醒你。

### ⚠️ 「渠道差异大于材料优化」是 `默认建议值`，不是实测结论

> **「不同渠道的回复率差异，通常大于你对材料做的任何优化」——这句话在本仓库里承重。** 它是"**先判渠道、再改讲法**"这个决策顺序的全部依据：复盘时先看分渠道回应率，得出"这是渠道问题"之后才轮到动表述。
>
> 但它是**一条未被验证的经验断言**，来源等级 `默认建议值`。**如果它在你身上不成立**（你只用一个渠道、或者材料本身有硬伤），照它走的代价很具体：**你会先去折腾渠道，拖慢真正该做的那件事——修表述。**
>
> 所以它值得你亲自验一次：台账攒够之后先看分渠道回应率的差距有多大，再决定信不信它。**验过之后把等级改成 `实践校准`，并写下你看到的差距。**

⭐ **顺带一条通用纪律**：**判断性断言也要标来源等级，不只是数字。** 上面这句躲过了"所有阈值都要标等级"这条规则整整一版，**因为它不长得像一个数字**。凡是被拿来支撑一个决策顺序、一次取舍、一个"通常"的说法，一律按阈值同等对待。

## 两条最容易被做坏的规则

### ⚠️ 「对方回应原话」要**原话**，不要压成分类标签

一旦压成「婉拒 / 待定 / 邀约」，就再也分不出**"薪资不匹配"**和**"方向不匹配"**了——而这两者指向完全不同的改法：前者要调阈值或换目标层级，后者要改定位。分类标签把这个区别永久抹掉，且不可恢复。

- 记原话，哪怕只有半句
- 记不全就记你记得的那部分 + 标注「大意」
- ⛔ **agent 不许在写入时"顺手归类"**。归类是分析阶段的事，登记阶段只做转录

### ⚠️ 「反向吸引」是最容易漏的一栏

对方**主动**来找你的那些，打上标记。

- **为什么**：它往往指向你自己没意识到的定位——别人看到的你，和你以为自己在卖的东西，经常不是一回事。这一栏是这个差距的唯一数据来源
- **不填会怎样**：定位复盘只能看到"我投的那些"的反馈，看不到"别人觉得我像什么"。前者验证的是你已有的假设，后者才可能推翻它
- 一并记下**对方是从哪找到你的**（如果知道）——那条路径本身就是信号

## 填表规则

1. **一次接触一行，不合并。** 同一家公司的三次沟通是三行。合并之后再也拆不开，而且时间信息会丢
2. **每发生一次接触就登记，不要攒着。** 攒到周末再补，回应原话一定已经变成你的转述了
3. **散着贴也行。** 如果你手上是一堆聊天记录、邮件、截图说明，直接给 agent，让它整理成表——**要求你先整理好再来是被禁止的**
4. **低于 〔10〕 条时不要做漏斗分析**（`默认建议值`）**。** 定位复盘模块会直接说"这个量级看不出漏斗形态"，那是正确行为，不是它偷懒

## 状态枚举（建议，可改）

`待投递` · `已投递` · `已读未回` · `已回复` · `约面中` · `面试中` · `已拒` · `我拒` · `已发 offer` · `搁置`

> ⚠️ **`我拒` 和 `已拒` 必须分开。** 合成一个"结束"会让你的漏斗看起来比实际差很多——**你主动拒掉的那些是判断在起作用，不是失败**。分不开这两者，会导致你在数据上看到"通过率很低"，然后错误地放宽必要条件。
