# 本次交付审阅

- 任务 / 日期：
- 完成状态：可审阅 / 部分完成 / 阻塞（选一）
- 本人审阅：待本人审阅 / 已审阅（无实际审阅不得选后者）
- 成品：列实际相对路径和用途；不列不存在的文件链接。
- 主要结论及依据：区分你给的 / 公开可查 / 我推测的，推测附核实路径。
- 本次策略：采用的参数、来源等级、用户策略版本或变更日期。
- 待确认与影响：问题集中列出，无则写无；说明是否影响正式使用。
- 实际检查：已打开的文件、链接、事实及格式检查；未做检查明确标未做。
- 下一步：用户只需 review 什么；Agent 后续负责什么；与报告、申请索引和台账结论一致。
- 交叉检查：不投岗位是否写明重评条件；重排后指代是否正确；检查数量是否来自工具统计。
