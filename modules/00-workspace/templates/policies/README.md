# 我的用户策略

这是用户本地文件，Agent 负责随使用维护。每次任务读取本目录；不用用户手工修改模块 SKILL。

- [preferences.md](preferences.md)：生效的执行偏好与可调参数；未设参数沿用模块标明的默认值，没有默认则标待确认。
- [changes.md](changes.md)：策略调整与恢复记录。
- 工作区根的 `positioning.md` 唯一维护求职条件与披露边界，本地引用路径为 `../positioning.md`，不在这里抄一份。

优先遵循用户明确要求；用户已明确给出的策略可直接生效。未设偏好可使用本模板或模块明确声明的默认值，来源记为模板默认或模块默认，不冒充用户要求。Agent 提议标待确认，不能自己放宽底线。经验可沉淀，但不等于授权外部操作。

模板维护入口：[交付规则](../../../../docs/delivery.md)、[工作区模块](../../README.md)。复制到私人工作区时删去这段模板维护入口，并把定位文件链接写成 `../positioning.md`。
