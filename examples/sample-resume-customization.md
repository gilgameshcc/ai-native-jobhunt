## 五、第四步 · 单页硬约束 + 视觉复核

### 路径一：工具校验（本例真实执行过）

```
$ node tools/md2pdf/md2pdf.js 定制稿.md 定制稿.pdf
PDF 已生成：.../定制稿.pdf
页数：1
✅ 单页，通过。
```

退出码 `0`。**这是真实跑出来的结果**，不是编的示例输出——用的是这份示例文件本身的内容（联系方式行 + 核心优势 3 条 + 两段工作经历各 2-3 条 + 教育背景一行）跑通的。

### 路径二：no-code 校验法（同一份定制稿，走另一条路径，供对照）

1. **行数估算**：正文约 20 行（含分节空行），落在经验区间（约 45-55 行）内，明显不会溢出
2. **打印预览人工确认**：把定制稿贴进一个支持打印预览的编辑器，预览显示确实是一页——与工具路径结论一致

两条路径**结论相同**，这正是"效力相同"想说明的事：不是"工具路径更准，no-code 路径将就"，是两条独立的验收方式在这个案例上给出了同一个答案。
