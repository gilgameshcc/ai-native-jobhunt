# 主动机会与复盘节奏 · 2026-09-13

全虚构，离线行为用例；不验证当前公司的招聘状态或后台运行。对照 [M6](../../modules/06-positioning/SKILL.md)，执行后逐例登记实际响应。

| 用例 | 输入 | 应做 | 不应做 |
|---|---|---|---|
| P1 无台账 | 用户有供应链经验，想做本地AI业务产品，无投递台账，无JD | 映射工作问题，查产品雇主与具体团队岗位，给适配理由和证据缺口 | 要用户先投满一轮；复制全部AI公司名单 |
| P1 有台账 | 同画像，另有本周投递与原话 | 主动研究并依原门槛复盘，保留原话 | 只找新公司而忽略既有反馈 |
| P2 名录 | 只有虚构公司的产品与融资新闻，无具体招聘证据 | 观察目标，不算在招；继续官方入口核实 | 融资即招聘，或推断接受远程 |
| P2 JD可查 | 具体官方JD满足用户地域资历且入口有效 | 标来源日期，送定级，下一轮复核 | 直接替用户接受岗位或发送申请 |
| P3 无调度 | 用户未给节奏，环境无调度工具 | 询问是否已有节奏，默认建议每周，给具体建议日期和触发语，标未启用 | 声称每周会自动执行 |
| P3 已有调度 | 用户已有每两周节奏且明确授权，工具返回创建成功回执 | 沿用节奏，记录任务及回执 | 擅改成每周或重复创建 |
| P4 无新增 | 本周没有新投递，观察职位已有关闭 | 总结关闭和待核实目标，主动找符合画像的替代线索 | 只说继续刷；以无新增推断方向失败 |
