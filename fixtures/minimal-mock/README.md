# 最小本地 mock 测试

范围：工作区初始化 → 岗位判断 → 策略更新与继续使用，以及简历模块缺材料时的独立降级。这是当前交付约定的最小冒烟验证，不代表八个模块的全部业务能力、真人效用或平台执行能力已验证。

已有成对文字样本检查规则的区分力；本方案增加真实 Agent 执行和文件验收。产品仍不要求用户安装测试运行器。

## 固定输入与通过条件

[evals.json](evals.json) 是可重复使用的 3 个输入及 10 条验收标准，所有材料从零虚构。执行者仅收到 prompt 和相应 SKILL，不看 assertions、他组结果或修订历史。`{output}` 替换为新建的临时测试根路径；工作区子目录 work / missing 开始必须不存在。

| 场景 | 关键能力 | 主要失败信号 |
|---|---|---|
| 建工作区并判断岗位 | Agent 建真实目录、整理事实、正确区分可继续与硬性排除、交付可审阅文件 | 只展示目录树；编成果数字；两个岗位都放行；只有空模板 |
| 复用与修改策略 | 偏好落盘且实际生效；保留历史；同岗位复用申请目录 | 只在聊天答应；旧记录被覆盖；复制出第二份同岗位档案；底线漂移 |
| 单模块缺材料 | 不依赖完整初始化；骨架与缺口落盘；诚实标部分完成 | 停在问卷；借用上个用户经历；把骨架说成可发送成稿 |

本轮“必需目录”明确指 `jobs/`、`triage/`、`runs/`、`assessments/`、`interviews/`、`resumes/`、`notes/`、`policies/`、`applications/`、`reviews/`；五份根契约为 `facts.md`、`positioning.md`、`ledger.md`、`discoveries.md`、`branches.md`，另有 `AGENTS.md`。这份清单对应工作区骨架，机械检查在执行期间即使用同一清单。

## 最小执行步骤

1. 冻结被测 SKILL、必要模板、docs 及其 SHA-256，记录运行时间、可见模型标识和工具范围。未知型号/用量写未暴露，不猜。约束无网络、无外部发送；只允许对本轮测试目录读写。
2. 为当前版和修改前版分别建相同的输入与空输出根；修改前版从修改之前的 git 版本提取。两组使用同一 Host 的默认模型和工具，分别放在全新上下文。一次各跑一轮即可，不为追求通过率重复抽样。
3. 依次执行场景 1、2、3；保存每轮原始最终回复和工具执行记录。场景 1 后快照整个 work；场景 2 前额外放入 `notes/用户保留.md`，内容为“用户原始记录：这段内容必须保留。”加一个换行。场景 2 后再快照；场景 3 用独立 missing 目录，不得继承前例个人材料。
4. 验收者直接读文件：检查五份契约、必需目录、产物内容、策略旧新值、相对链接目标、原文与判断分离。逐字或按 hash 比较 facts、positioning、jobs 原文、旧 review 与保留文件；目录存在不能代替有用成品。
5. 内容判定依照预先固定的 assertions，逐条写通过/失败和文件证据。特别检查未知数字不进事实正文、纯外包确实不投、缺经历只部分完成。客观检查用临时脚本即可，不向产品增加运行依赖。
6. 校验检查器：复制产物后人为删审阅文件、破坏一个链接、修改保留文件；检查器必须拒绝这些副本，同时接受原始合格输出。这是在测检查器，不能算 Agent 的成功次数。
7. 任一关键能力失败就记录首跑失败；只修实际缺口，在新目录重跑受影响场景，保留旧产物。不得手工补齐执行者产物再计为通过。

## 判定与证据

全部 10 条满足才称“本轮最小 mock 通过”。与旧版比较只说明此输入下观察到的差异；单次运行没有统计置信度。明确列出此 mock 未覆盖：跨会话记忆、实际目录授权拒绝、无写工具、PDF 排版、真实网站投递、其它模块业务和真人采用。独立补充实测须单列结果，不合并进 mock 通过率。

PDF 的最小补充验收：用全虚构中文简历覆盖标题、列表、表格，实际导出并检查 A4 单页、退出码 0、全文顺序及看图无乱码/重叠/裁切；另加超长文本负例，检查多页、退出码 1、末段完整。保存源文、PDF、日志和逐页图，独立审阅事实及视觉效果。真实平台验证另需用户明确授权；发送前核对目标，发送后以实际消息确认，结果不明不重试。共享标签页被其它任务改变时暂停发送，不能把本地文案准备完成计为已投递。

多轮场景 1→2 可以在同一执行会话内完成，但不能因此声称已验证跨会话恢复。原始输出、快照、检查器、逐条判定和版本 hash 应保存在维护者测试记录中；公开报告只引用虚构内容，不包含机器绝对路径或会话标识。

测试预算建议：3 个场景 × 当前/旧版各一次；修复后仅重跑失败范围。时间或工具不足时标未完成，不把静态门禁当行为测试。

入口：[测试目录](../README.md) · [交付规则](../../docs/delivery.md)。执行结果完成后在本目录增加报告。
